# Основной маршрут подготовки

[[Собеседования/00. Карта раздела|Карта банка]]

## 1. Основное

66 пунктов в восьми блоках: короткие ответы, задачи на код/тесты и два frontend design-разбора. Это конечный проход, а не требование выучить каждую карточку банка. Проходи один блок за несколько занятий, если практика требует больше времени. Известный механизм можно проверить незнакомым вариантом вместо повторного чтения.

Для вопроса: ответ за 30–90 секунд → применение и ограничение → уточнения → короткий ответ для сверки. Для практики: сначала своё решение и проверки, затем разбор. Если нужен фундамент для решения, открой учебную ссылку и вернись, не добавляя весь учебный раздел к обязательному маршруту.

### Когда завершить основной проход

Нужно самостоятельно объяснить механизм, решить выбранные задачи и сохранить корректность при одном новом условии: обратном порядке ответов, другой организации, ошибке или изменённом требовании. В design-разборе должны быть владелец состояния, API, отказ, проверка и компромисс. Один выученный ответ не подтверждает готовность.

Фиксируй конкретный пробел в [[Собеседования/02. Журнал проверки|существующем журнале]]. Если пробная смешанная сессия не выявляет нового существенного пробела, основной маршрут закончен; «Расширенное» не становится вторым обязательным экзаменом. Полного покрытия всех будущих собеседований банк не обещает.
