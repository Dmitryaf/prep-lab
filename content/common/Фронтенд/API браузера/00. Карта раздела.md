# Browser API

> [!summary]
> Раздел собирает браузерные API, которые часто нужны на frontend-собеседованиях: DOM, события, рендеринг, хранение данных, `fetch`, CORS, workers и Service Workers. Цель раздела - понимать практическую модель браузера, а не перечислить все Web API.

## Что нужно понимать после прохождения раздела

- как браузер представляет HTML как DOM-дерево;
- как выбирать, изменять и обходить DOM-узлы;
- как работают `addEventListener`, объект события, всплытие, погружение и делегирование;
- как Event Loop связан с рендерингом кадра;
- что на практике означают style recalculation, layout, paint и composite;
- когда выбирать `localStorage`, `sessionStorage`, cookies или IndexedDB;
- почему `fetch()` не считает HTTP 404 сетевой ошибкой;
- как объяснить правило одного источника, CORS и предварительный запрос OPTIONS;
- как отменять запросы и защищаться от устаревших ответов;
- когда нужны Web Workers и Service Workers.
