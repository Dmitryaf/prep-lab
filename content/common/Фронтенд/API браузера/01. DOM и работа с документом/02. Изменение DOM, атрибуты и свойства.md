# Изменение DOM, атрибуты и свойства

> [!summary]
> DOM можно менять через свойства объектов и методы документа: создавать элементы, менять текст, классы, атрибуты и вставлять узлы в дерево. Главная практическая задача - делать это понятно и без лишних дорогих перерасчётов.

## Зачем понимать тему

Даже если проект написан на React или Vue, frontend-разработчик должен понимать, что в итоге меняется DOM. Это помогает объяснить делегирование событий, утечки из обработчиков, XSS-риски `innerHTML` и производительность изменений.

## Создание и вставка элементов

```js
const list = document.querySelector('#list');
const item = document.createElement('li');

item.textContent = 'Новая задача';
item.classList.add('item');

list.append(item);
```

Для текста почти всегда безопаснее использовать `textContent`, а не собирать HTML-строку.

## textContent, innerHTML и insertAdjacentHTML

| API | Что делает | Риск |
| --- | --- | --- |
| `textContent` | вставляет текст как текст | безопасный выбор по умолчанию |
| `innerHTML` | парсит строку как HTML | опасен с пользовательскими данными |
| `insertAdjacentHTML()` | вставляет HTML в выбранную позицию | тот же риск, что у HTML-строк |

```js
message.textContent = userInput;
```

Так пользовательский ввод не станет разметкой.

## Атрибуты и свойства

Атрибут - то, что записано в HTML. Свойство - поле DOM-объекта.

```html
<input id="name" value="Alex">
```

```js
const input = document.querySelector('#name');

console.log(input.getAttribute('value')); // Alex
console.log(input.value); // текущее значение поля

input.value = 'Maria';

console.log(input.getAttribute('value')); // Alex
console.log(input.value); // Maria
```

Для текущего состояния формы обычно нужны свойства (`value`, `checked`, `disabled`). Для произвольных HTML-атрибутов - `getAttribute()` и `setAttribute()`.

## classList и dataset

```js
button.classList.toggle('is-active', isActive);
button.dataset.userId = '42';

console.log(button.dataset.userId); // 42
```

`classList` лучше ручной склейки строки `className`, когда нужно добавлять, удалять или переключать отдельные классы.

## Оптимизация изменений DOM

Практические правила:

- собрать несколько элементов в `DocumentFragment`, а потом вставить один раз;
- не читать layout-свойства после каждой записи стилей в цикле;
- для визуальных изменений, связанных с кадром, использовать `requestAnimationFrame()`;
- удалять обработчики и таймеры, если они живут дольше элемента или компонента.

```js
const fragment = document.createDocumentFragment();

for (const title of titles) {
  const item = document.createElement('li');
  item.textContent = title;
  fragment.append(item);
}

list.append(fragment);
```

## Частые ошибки

- Использовать `innerHTML` для непроверенных пользовательских данных.
- Путать начальный HTML-атрибут `value` и текущее свойство `input.value`.
- Читать `offsetWidth` после каждой записи `style.width` в большом цикле.
- Создавать элементы через строковую конкатенацию, когда проще и безопаснее DOM API.
- Забывать про утечки из обработчиков событий.

## Как ответить на собеседовании за одну минуту

DOM меняют через методы вроде `createElement`, `append`, `remove`, свойства вроде `textContent`, `value`, `classList` и атрибуты через `getAttribute`/`setAttribute`. Атрибуты - это часть HTML-разметки, а свойства - текущее состояние DOM-объекта, поэтому они не всегда совпадают, особенно у форм. Для текста безопаснее `textContent`; `innerHTML` парсит строку как HTML и опасен с пользовательским вводом. Для производительности изменения лучше группировать и не смешивать частые чтения layout со стилевыми записями.
