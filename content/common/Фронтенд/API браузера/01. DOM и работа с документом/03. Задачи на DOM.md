# Задачи на DOM

## Задача 1. children или childNodes

```html
<ul id="list">
  <li>A</li>
  <li>B</li>
</ul>
```

```js
const list = document.querySelector('#list');

console.log(list.children.length);
console.log(list.childNodes.length);
```

> [!question]- Разбор
> `children.length` будет `2`, потому что учитывает только элементы `li`.
>
> В показанной разметке `childNodes.length` будет `5`: два `li` и три текстовых узла с переносами строк — перед первым элементом, между элементами и после второго. Если убрать пробелы и переносы из HTML, текстовых узлов не будет.

## Задача 2. Безопасная вставка

Нужно вывести комментарий пользователя в блок `.comment`. Почему это плохо?

```js
comment.innerHTML = userComment;
```

> [!question]- Разбор
> `innerHTML` разбирает строку как разметку. Например, комментарий с тегом img и обработчиком onerror может создать элемент и выполнить чужой код. Если нужно показать сам текст комментария, используем:
>
> ```js
> comment.textContent = userComment;
> ```

## Задача 3. Текущее значение input

```html
<input id="name" value="Alex">
```

Пользователь руками ввёл `Maria`. Что покажет код?

```js
const input = document.querySelector('#name');

console.log(input.getAttribute('value'));
console.log(input.value);
```

> [!question]- Разбор
> `getAttribute('value')` вернёт начальное значение из HTML: `Alex`.
>
> `input.value` вернёт текущее значение DOM-свойства: `Maria`.
