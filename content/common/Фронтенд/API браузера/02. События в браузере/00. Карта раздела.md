## Что нужно понимать

- `addEventListener()` регистрирует listener на `EventTarget`;
- объект события хранит `type`, `target`, `currentTarget`, `defaultPrevented` и другие данные;
- `target` - исходная цель события, `currentTarget` - элемент, чей listener выполняется сейчас;
- событие проходит capture, target и bubble phases;
- делегирование использует всплытие, чтобы обрабатывать много элементов одним listener;
- `preventDefault()` отменяет действие по умолчанию, но не останавливает распространение;
- `stopPropagation()` останавливает дальнейшее распространение, но не отменяет действие по умолчанию.
