# addEventListener и объект события

> [!summary]
> События позволяют браузеру сообщать JavaScript о действиях пользователя и изменениях платформы. `addEventListener()` добавляет функцию-обработчик, а объект события передаёт детали произошедшего.

## Зачем понимать тему

События лежат в основе кликов, ввода, форм, клавиатуры, drag-and-drop и пользовательских взаимодействий. На собеседовании часто спрашивают `target`/`currentTarget`, удаление listener, `this` внутри обработчика и отличие `preventDefault()` от `stopPropagation()`.

## Базовая модель

```js
button.addEventListener('click', (event) => {
  console.log(event.type); // click
  console.log(event.target);
});
```

В примере мы просим кнопку вызвать переданную функцию при клике. Браузер передаёт ей объект события: из него можно узнать, куда нажали и какие клавиши были зажаты. Кнопка поддерживает интерфейс EventTarget, а такую функцию называют обработчиком, или listener.

## options addEventListener

```js
button.addEventListener('click', handleClick, {
  once: true,
  passive: true,
  capture: false,
});
```

| Опция | Что означает |
| --- | --- |
| `capture` | listener сработает на фазе погружения |
| `once` | listener удалится после первого вызова |
| `passive` | listener обещает не вызывать `preventDefault()` |
| `signal` | listener можно удалить через `AbortController` |

```js
const controller = new AbortController();

button.addEventListener('click', handleClick, {
  signal: controller.signal,
});

controller.abort();
```

## target и currentTarget

```html
<button id="button">
  <span>Save</span>
</button>
```

```js
button.addEventListener('click', (event) => {
  console.log(event.target); // span, если кликнули по тексту
  console.log(event.currentTarget); // button
});
```

Если обработчик установлен на кнопке, а пользователь нажал на иконку внутри неё, `target` укажет на иконку. `currentTarget` в обработчике кнопки укажет на саму кнопку: это элемент, чей обработчик сейчас выполняется.

## this внутри обработчика

В обычной функции, зарегистрированной через `addEventListener`, `this` обычно равен `currentTarget`.

```js
button.addEventListener('click', function (event) {
  console.log(this === event.currentTarget); // true
});
```

У стрелочной функции собственного `this` нет, поэтому она берёт `this` снаружи. Подробная модель: [[Фронтенд/JavaScript/03. Контекст this/01. Как определяется this|Как определяется this]].

## Удаление listener

Чтобы удалить listener, должны совпадать тип события, ссылка на функцию и значение `capture`. Опции `once`, `passive` и `signal` для сопоставления не нужны:

```js
function handleClick() {
  console.log('clicked');
}

button.addEventListener('click', handleClick);
button.removeEventListener('click', handleClick);
```

Так не сработает:

```js
button.addEventListener('click', () => console.log('clicked'));
button.removeEventListener('click', () => console.log('clicked'));
```

Это две разные функции.

## Частые ошибки

- Создавать anonymous listener и потом пытаться удалить его другой anonymous функцией.
- Путать `target` и `currentTarget`.
- Ожидать `this` в стрелочной функции как у обычного обработчика.
- Не очищать listener в долгоживущих компонентах.
- Вызывать `preventDefault()` в `passive` listener.

## Как ответить на собеседовании за одну минуту

Через `addEventListener()` я задаю, какую функцию вызвать при событии. Например, при клике по кнопке браузер вызовет обработчик и передаст ему объект события. Если нажали на иконку внутри кнопки, `target` будет иконкой, а `currentTarget` — кнопкой.

Опции меняют поведение подписки: `once` оставляет один вызов, `capture` выбирает фазу погружения, `passive` сообщает, что обработчик не будет отменять стандартное действие. Через `signal` можно снять подписку при отмене AbortController.

Для `removeEventListener()` сохраняю ссылку на исходную функцию: новая функция с таким же текстом её не заменит. Тип события и `capture` тоже должны совпасть. В обычном обработчике `this` обычно равен `currentTarget`, а стрелка берёт его из внешнего кода.

> [!note]- Углубление: EventTarget в DOM Standard
> DOM Standard определяет `EventTarget` как интерфейс с `addEventListener()`, `removeEventListener()` и `dispatchEvent()`. События не ограничены DOM-элементами: такой интерфейс используют, например, `window`, `document`, `AbortSignal` и многие браузерные API.
