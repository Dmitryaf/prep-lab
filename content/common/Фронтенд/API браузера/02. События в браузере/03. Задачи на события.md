# Задачи на события

## Задача 1. target и currentTarget

```html
<button id="button">
  <span id="label">Save</span>
</button>
```

```js
button.addEventListener('click', (event) => {
  console.log(event.target.id);
  console.log(event.currentTarget.id);
});
```

Пользователь кликнул по `span`. Что выведется?

> [!question]- Разбор
> Результат:
>
> ```text
> label
> button
> ```
>
> `target` - исходная цель клика. `currentTarget` - элемент, на котором сейчас выполняется listener.

## Задача 2. preventDefault или stopPropagation

Нужно отправить форму через `fetch()` и не перезагружать страницу. Что использовать?

> [!question]- Разбор
> Нужно вызвать `event.preventDefault()` в обработчике `submit`.
>
> `stopPropagation()` не отменяет стандартный submit формы. Он только останавливает распространение события.

## Задача 3. Делегирование

Напиши listener на `ul`, который удаляет `li` при клике по кнопке с `data-remove`.

> [!question]- Разбор
> ```js
> list.addEventListener('click', (event) => {
>   const button = event.target.closest('[data-remove]');
>
>   if (!button || !list.contains(button)) {
>     return;
>   }
>
>   button.closest('li')?.remove();
> });
> ```
>
> `closest()` нужен, потому что клик мог прийти по вложенной иконке или тексту внутри кнопки.
