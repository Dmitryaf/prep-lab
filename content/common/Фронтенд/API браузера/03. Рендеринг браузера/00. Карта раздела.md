## Что нужно понимать

- браузер строит DOM и CSSOM, затем использует их для отображения страницы;
- layout считает геометрию, paint рисует пиксели, composite собирает слои;
- тяжёлый JavaScript и бесконечные microtasks могут задержать кадр;
- `requestAnimationFrame()` подходит для визуальных обновлений перед кадром;
- `requestIdleCallback()` подходит только для некритичной работы, когда браузер имеет свободное время;
- оптимизация DOM часто сводится к уменьшению лишнего layout/paint и к работе с main thread.
