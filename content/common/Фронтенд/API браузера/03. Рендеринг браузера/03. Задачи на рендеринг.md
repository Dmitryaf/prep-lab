# Задачи на рендеринг

## Задача 1. Почему интерфейс зависает

```js
button.addEventListener('click', () => {
  const start = Date.now();

  while (Date.now() - start < 2000) {}

  status.textContent = 'Done';
});
```

Почему текст не обновляется сразу?

> [!question]- Разбор
> Обработчик клика выполняется как макрозадача JavaScript в основном потоке. Пока цикл не закончится, браузер не может перейти к обработке следующего ввода и обновлению изображения. Изменение `textContent` произойдёт в DOM, но пользователь увидит результат только когда основной поток освободится и браузер сможет обновить кадр.

## Задача 2. Forced layout

Что потенциально плохо в коде?

```js
for (const item of items) {
  item.style.height = '40px';
  total += item.offsetHeight;
}
```

> [!question]- Разбор
> Код записывает стиль и сразу читает layout-свойство. Браузеру может понадобиться синхронно пересчитать геометрию на каждой итерации. Лучше сначала прочитать нужные размеры, потом отдельно сделать записи, либо пересмотреть алгоритм.

## Задача 3. Что выбрать для анимации

Нужно плавно двигать элемент. Что лучше попробовать первым: `left` или `transform: translateX()`?

> [!question]- Разбор
> Обычно лучше начать с `transform`, если это подходит по смыслу. Изменение `left` влияет на геометрию и может требовать layout. `transform` часто может обрабатываться дешевле на этапе композиции. Это не абсолютный закон, но хорошее практическое правило.
