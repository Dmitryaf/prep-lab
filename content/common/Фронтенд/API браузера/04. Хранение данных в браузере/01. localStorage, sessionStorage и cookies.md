# localStorage, sessionStorage и cookies

> [!summary]
> Тему интерфейса можно сохранить в `localStorage`, а временное состояние текущей вкладки — в `sessionStorage`. Cookie отличается тем, что браузер может сам приложить её к запросу на сервер. Поэтому cookie часто используют для серверной сессии.

## Зачем понимать тему

На собеседовании часто спрашивают, где хранить токен, почему `localStorage` не подходит для больших данных, чем cookies отличаются от Web Storage и почему синхронный storage может быть проблемой.

## Web Storage

`localStorage` и `sessionStorage` имеют похожий API:

```js
localStorage.setItem('theme', 'dark');
const theme = localStorage.getItem('theme');
localStorage.removeItem('theme');
```

Ключи и значения - строки. Объекты нужно сериализовать:

```js
const settings = { theme: 'dark' };
localStorage.setItem('settings', JSON.stringify(settings));

const saved = JSON.parse(localStorage.getItem('settings'));
```

## localStorage vs sessionStorage

| Свойство | localStorage | sessionStorage |
| --- | --- | --- |
| Область | origin | origin и текущая страница/вкладка |
| Жизнь | обычно переживает закрытие браузера | обычно живёт до закрытия вкладки |
| API | синхронный | синхронный |
| Данные | строки | строки |

Событие `storage` не приходит в документ, который выполнил запись. Для `localStorage` его получают другие документы того же origin с доступом к той же области хранения. Для `sessionStorage` область дополнительно ограничена текущей вкладкой: событие может получить её same-origin iframe, но не соседняя вкладка. Это уведомление об изменении, а не транзакционная блокировка между вкладками.

## Cookies

Cookies - маленькие пары `name=value`, которые браузер может автоматически отправлять на сервер с подходящими HTTP-запросами.

```http
Set-Cookie: sessionId=abc; HttpOnly; Secure; SameSite=Lax
```

Практически важные атрибуты:

| Атрибут | Зачем нужен |
| --- | --- |
| `HttpOnly` | cookie недоступна из JavaScript |
| `Secure` | отправлять только по HTTPS |
| `SameSite` | ограничивает отправку в cross-site сценариях |
| `Expires`/`Max-Age` | задаёт срок жизни |
| `Path`/`Domain` | ограничивает область отправки |

## Сравнение

| Задача | Что выбрать |
| --- | --- |
| Тема интерфейса | `localStorage` |
| Черновик формы в текущей вкладке | `sessionStorage` |
| Серверная сессия | cookie с `HttpOnly`, `Secure`, `SameSite` |
| Большие offline-данные | IndexedDB |
| Данные, которые нельзя читать JS | не `localStorage`; чаще HttpOnly cookie |

## Частые ошибки

- Хранить чувствительные токены в `localStorage` и считать это безопасным.
- Забывать, что Web Storage синхронный и может блокировать основной поток.
- Считать, что cookies и `localStorage` одинаково участвуют в запросах.
- Хранить большие массивы JSON в `localStorage`.
- Полагаться на точный размер quota как на стабильный стандарт.

## Как ответить на собеседовании за одну минуту

Для небольшой настройки вроде тёмной темы я выберу `localStorage`: значение останется после перезагрузки и обычно переживёт закрытие браузера. Если состояние нужно только в текущей вкладке, подойдёт `sessionStorage`. Оба хранят строки в пределах origin и работают синхронно, поэтому большой JSON может задержать интерфейс.

Cookie браузер отправляет с подходящими HTTP-запросами сам. Это удобно для серверной сессии: сервер может поставить `HttpOnly`, чтобы JavaScript не прочитал идентификатор. `Domain`, `Path`, `SameSite` и `Secure` определяют, с какими запросами cookie уйдёт.

Для большого каталога или офлайн-записей выберу IndexedDB. Ошибки записи всё равно нужно обрабатывать: доступное место и правила очистки зависят от браузера.

> [!note]- Углубление: quota и privacy
> Браузер ограничивает место для данных сайта и при некоторых условиях может их удалить. Правила зависят от типа хранилища, свободного места, приватного режима и настроек пользователя. Например, `setItem()` может завершиться с `QuotaExceededError`. В таком случае приложение должно сохранить несохранённый ввод и предложить повтор или другой способ сохранения. Для важных данных нужна копия за пределами одного браузера.
