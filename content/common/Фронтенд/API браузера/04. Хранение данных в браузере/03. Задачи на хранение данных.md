# Задачи на хранение данных

## Задача 1. Где хранить тему

Пользователь выбрал тёмную тему. Нужно сохранить выбор между перезагрузками страницы. Что выбрать?

> [!question]- Разбор
> Подойдёт `localStorage`: это маленькое некритичное строковое значение, которое нужно восстановить на том же origin после перезагрузки.

## Задача 2. Серверная сессия

Нужно хранить идентификатор серверной сессии так, чтобы JavaScript не мог его прочитать. Что выбрать?

> [!question]- Разбор
> Обычно выбирают cookie с `HttpOnly`, `Secure` и подходящим `SameSite`. `HttpOnly` не даёт JavaScript прочитать cookie через `document.cookie`.

## Задача 3. Большой offline-каталог

Приложению нужно хранить тысячи товаров для offline-поиска. Что выбрать?

> [!question]- Разбор
> Выберу IndexedDB: товары можно хранить как объекты и искать по ключам или индексам. С `localStorage` пришлось бы сериализовать каталог в строку и синхронно читать или записывать её, задерживая основной поток.
