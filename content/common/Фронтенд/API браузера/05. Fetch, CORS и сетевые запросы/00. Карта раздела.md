## Что нужно понимать

- `fetch()` возвращает Promise с `Response`;
- HTTP-статусы `404` и `500` обычно не отклоняют Promise сами по себе;
- сетевые ошибки, abort и ошибки парсинга нужно различать;
- правило одного источника ограничивает чтение ответов других источников из JavaScript;
- CORS - серверное разрешение браузеру отдать response JavaScript-коду;
- preflight - предварительный `OPTIONS`-запрос для некоторых запросов к другому источнику;
- `AbortController` отменяет клиентское ожидание результата, но не гарантирует откат серверной операции;
- race condition решается отменой, игнорированием устаревшего результата или обоими подходами.
