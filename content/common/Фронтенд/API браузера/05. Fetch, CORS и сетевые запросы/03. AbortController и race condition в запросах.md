# AbortController и race condition в запросах

> [!summary]
> `AbortController` позволяет отменить клиентскую асинхронную операцию, если API поддерживает `AbortSignal`. Race condition возникает, когда старый запрос отвечает позже нового и перетирает актуальное состояние.

## AbortController

```js
const controller = new AbortController();

fetch('/api/search?q=cat', {
  signal: controller.signal,
}).catch((error) => {
  if (error.name === 'AbortError') {
    return;
  }

  throw error;
});

controller.abort();
```

Отмена говорит клиентской операции, что результат больше не нужен. Она не гарантирует, что сервер "откатил" уже начатую работу.

## Race condition и устаревшие ответы

Пользователь быстро печатает:

```text
c -> ca -> cat
```

Запрос `c` может вернуться позже `cat`. Если просто рендерить каждый ответ, старые данные перетрут новые.

```js
let requestId = 0;

async function search(query) {
  const currentRequestId = ++requestId;
  const response = await fetch(`/api/search?q=${encodeURIComponent(query)}`);
  const result = await response.json();

  if (currentRequestId !== requestId) {
    return;
  }

  render(result);
}
```

## Отмена предыдущего запроса

```js
let currentController = null;

async function search(query) {
  currentController?.abort();
  currentController = new AbortController();

  try {
    const response = await fetch(`/api/search?q=${encodeURIComponent(query)}`, {
      signal: currentController.signal,
    });

    if (!response.ok) {
      throw new Error(`HTTP ${response.status}`);
    }

    render(await response.json());
  } catch (error) {
    if (error.name === 'AbortError') {
      return;
    }

    showError(error);
  }
}
```

В сложных UI часто комбинируют отмену и проверку актуальности.

## Частые ошибки

- Думать, что `abort()` откатывает серверную операцию.
- Показывать ошибку пользователю при ожидаемом `AbortError`.
- Защищаться только debounce, хотя ответы всё равно могут прийти не по порядку.
- Не учитывать race condition между несколькими независимыми источниками данных.

## Как ответить на собеседовании за одну минуту

`AbortController` создаёт `signal`, который можно передать в `fetch()` и другие API. Когда вызываем `abort()`, операция на клиенте завершается с ошибкой abort, и результат больше не нужен. Это не означает автоматический откат на сервере. Race condition в запросах - ситуация, когда старый response приходит позже нового и перетирает актуальный UI. Решения: отменять предыдущий запрос, игнорировать устаревший результат через `requestId`, либо использовать оба подхода.
