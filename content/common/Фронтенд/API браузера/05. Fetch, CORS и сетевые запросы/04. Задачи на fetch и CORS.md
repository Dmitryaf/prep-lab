# Задачи на fetch и CORS

## Задача 1. Почему catch не сработал

```js
try {
  const response = await fetch('/missing');
  console.log('ok');
} catch (error) {
  console.log('error');
}
```

Сервер вернул `404`. Что вероятнее выведется?

> [!question]- Разбор
> Вероятнее всего:
>
> ```text
> ok
> ```
>
> `fetch()` обычно не отклоняет Promise из-за HTTP-статуса. Нужно проверить `response.ok`.

## Задача 2. Где чинить CORS

Frontend получает CORS error при запросе к API. Где обычно нужно исправлять проблему?

> [!question]- Разбор
> На сервере API или на dev proxy, который отвечает за серверную часть. CORS - разрешение браузеру читать response, выраженное в HTTP-заголовках ответа. Клиент не может сам выдать себе это разрешение.

## Задача 3. Устаревший ответ

Пользователь быстро меняет фильтр. Первый запрос отвечает последним и перетирает UI. Назови два решения.

> [!question]- Разбор
> 1. Отменять предыдущий `fetch()` через `AbortController`.
> 2. Хранить `requestId` или timestamp и игнорировать response, если он уже не актуален.
>
> В сложном UI часто используют оба подхода.
