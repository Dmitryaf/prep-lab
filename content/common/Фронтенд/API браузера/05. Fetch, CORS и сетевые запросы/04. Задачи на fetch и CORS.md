# Задачи на fetch и CORS

## Задача 1. Почему catch не сработал

```js
try {
  const response = await fetch('/missing');
  console.log('ok');
} catch (error) {
  console.log('error');
}
```

Сервер вернул `404`. Что вероятнее выведется?

> [!question]- Разбор
> Вероятнее всего:
>
> ```text
> ok
> ```
>
> `fetch()` обычно не отклоняет Promise из-за HTTP-статуса. Нужно проверить `response.ok`.

## Задача 2. Где чинить CORS

Frontend получает CORS error при запросе к API. Где обычно нужно исправлять проблему?

> [!question]- Разбор
> Исправление обычно нужно на сервере API или в настроенном серверном proxy. Именно сервер задаёт заголовки, по которым браузер разрешает странице читать ответ. Изменением клиентского JavaScript выдать себе это разрешение нельзя.

## Задача 3. Устаревший ответ

Пользователь быстро меняет фильтр. Первый запрос отвечает последним и перетирает UI. Назови два решения.

> [!question]- Разбор
> 1. Отменять предыдущий `fetch()` через `AbortController`.
> 2. Хранить возрастающий `requestId` и игнорировать ответ, если он уже не актуален. Проверять актуальность также перед показом ошибки и снятием `loading`: два запроса могут начаться в одну миллисекунду, поэтому время само по себе не гарантирует уникальность.
>
> В сложном UI часто используют оба подхода.
