# Web Workers

## Порядок изучения

1. [[Фронтенд/API браузера/06. Web Workers/01. Web Workers и main thread|Web Workers и main thread]]

## Что нужно понимать

- Web Worker запускает JavaScript в отдельном контексте выполнения, не в основном потоке;
- Web Worker полезен для задач со сложными вычислениями, которые мешают интерфейсу отвечать на действия пользователя;
- общение идёт через сообщения, а не через общий доступ к DOM;
- данные обычно копируются алгоритмом структурированного клонирования, а некоторые объекты можно передавать с передачей владения без копирования;
- worker не решает сетевые задержки и не ускоряет сам DOM.
