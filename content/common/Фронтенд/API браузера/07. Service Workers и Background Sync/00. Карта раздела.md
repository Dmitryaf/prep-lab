# Service Workers и Background Sync

## Порядок изучения

1. [[Фронтенд/API браузера/07. Service Workers и Background Sync/01. Service Workers, Cache API и Background Sync|Service Workers, Cache API и Background Sync]]

## Что нужно понимать

- Service Worker - скрипт-посредник между страницей и сетью для своего scope;
- он может перехватывать `fetch` requests и отвечать из Cache API;
- Service Worker живёт отдельно от страницы и не имеет доступа к DOM;
- новая версия проходит установку и активацию; пока открытые страницы используют старую, она может оставаться в ожидании;
- Background Sync позволяет отложить повторную отправку, когда сеть восстановится, если API поддерживается браузером.
