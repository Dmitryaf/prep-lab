## Быстрое повторение

- семантическая структура документа;
- формы, labels, keyboard navigation и ARIA basics;
- cascade, specificity, inheritance и source order;
- box model, position и stacking contexts;
- выбор Flexbox или Grid;
- responsive layout, container queries и изображения;
- transitions/transforms без лишней нагрузки на layout;
- организация CSS в компонентном приложении.

## Приоритеты

- P0: семантика, формы, cascade, box model, Flex/Grid, responsive.
- P1: accessibility patterns, animations, организация CSS.
- P2: внутреннее устройство CSSOM, сложные доступные виджеты с ARIA, Houdini и особенности разных браузеров.
