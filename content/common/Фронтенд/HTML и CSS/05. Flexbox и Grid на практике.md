# Flexbox и Grid на практике

> [!summary]
> Flexbox удобен, когда нужно распределить элементы вдоль одной оси. Grid — когда важны строки и колонки вместе. Выбор начинается с расположения элементов, а не с предпочтения одной технологии.

## Flexbox

```css
.toolbar {
  display: flex;
  align-items: center;
  justify-content: space-between;
  gap: 12px;
}
```

Flex работает вдоль main axis и cross axis:

- `flex-direction` задает main axis;
- `justify-content` распределяет вдоль main axis;
- `align-items` выравнивает по cross axis;
- `gap` задает расстояние между items.

## Flex item sizing

```css
.sidebar {
  flex: 0 0 280px;
}

.content {
  flex: 1 1 auto;
  min-width: 0;
}
```

`flex` - сокращение для `flex-grow`, `flex-shrink`, `flex-basis`. Частая практическая деталь: `min-width: 0` помогает flex-item с длинным контентом реально сжиматься.

## Grid

```css
.layout {
  display: grid;
  grid-template-columns: 240px minmax(0, 1fr);
  gap: 24px;
}
```

Grid задает строки и колонки. Он удобен для:

- page layout;
- карточных сеток;
- dashboard;
- равномерных колонок;
- областей с `grid-template-areas`.

## Responsive grid

```css
.cards {
  display: grid;
  grid-template-columns: repeat(auto-fit, minmax(min(100%, 240px), 1fr));
  gap: 16px;
}
```

Так сетка подбирает количество колонок по доступной ширине. `min(100%, 240px)` позволяет единственной колонке сжаться в контейнере уже 240px; фиксированный минимум 240px создал бы переполнение.

## Flexbox vs Grid

| Задача | Выбор |
|---|---|
| выровнять кнопки в toolbar | Flexbox |
| навигация в строку с gap | Flexbox |
| карточки в несколько колонок | Grid |
| layout sidebar + content | Grid или Flexbox, Grid часто яснее |
| центрировать один элемент | Flexbox или Grid |
| двумерное расположение | Grid |

## Частые ошибки

- Использовать Flexbox для сложной двумерной сетки.
- Использовать Grid для простого inline toolbar без причины.
- Забывать `gap` и делать отступы через margin на items.
- Не задавать `min-width: 0` для flex-item с длинным текстом.
- Путать `align-items` и `justify-content` при смене `flex-direction`.
- Делать фиксированные колонки без адаптива.

## Как ответить на собеседовании за одну минуту

Для панели с заголовком и кнопками я обычно выберу Flexbox: он удобно распределяет элементы вдоль главной оси и выравнивает по поперечной. Направление главной оси задаёт `flex-direction`, поэтому свойства выравнивания нужно понимать относительно этой оси, а не как «горизонтально» и «вертикально».

Если карточки должны попадать в общие колонки и строки, выберу Grid. У перенесённых строк Flexbox размеры распределяются отдельно, а Grid связывает их общей сеткой. Это удобно и для страницы с боковой панелью, и для набора карточек.

В обоих случаях использую `gap` и проверяю узкую ширину. Длинному содержимому внутри flex-элемента иногда нужен `min-width: 0`, чтобы оно могло сжаться.
