# Практикум по HTML и CSS

> [!summary]
> Задачи покрывают типовые middle/middle+ вопросы: семантика, формы, доступность, каскад, box model, Flex/Grid, responsive layout, stacking context, CSS variables и pseudo-selectors.

## Задача 1. Выбор семантического тега

Нужно сверстать самостоятельную карточку новости в списке. Какой тег выбрать для карточки и почему?

> [!question]- Разбор
> Если карточка представляет самостоятельный материал с заголовком и ссылкой на полную новость, подходит `article`. Если это просто визуальный блок без самостоятельного смысла, можно использовать `div`.

## Задача 2. Исправить несемантическую разметку

```html
<div class="header">
  <div class="menu">
    <div onclick="goHome()">Главная</div>
  </div>
</div>
```

> [!question]- Разбор
> ```html
> <header>
>   <nav aria-label="Основная навигация">
>     <a href="/">Главная</a>
>   </nav>
> </header>
> ```
>
> Переход должен быть ссылкой с `href`, а не кликабельным `div`.

## Задача 3. Формы и label

Исправь поле email без label:

```html
<input placeholder="Email">
```

> [!question]- Разбор
> ```html
> <label for="email">Email</label>
> <input id="email" name="email" type="email" autocomplete="email">
> ```
>
> Placeholder не заменяет label: он исчезает при вводе и не всегда дает доступное имя.

## Задача 4. Accessibility basics

Что не так с кнопкой?

```html
<div class="button" role="button">Сохранить</div>
```

> [!question]- Разбор
> Лучше использовать нативный элемент:
>
> ```html
> <button type="button">Сохранить</button>
> ```
>
> `role="button"` сообщает назначение элемента, но сам div не начинает получать фокус, нажиматься Enter или Space и поддерживать disabled как обычная кнопка. С нативным button это поведение уже есть.

## Задача 5. Specificity

Какой цвет будет у заголовка?

```html
<h2 id="title" class="card__title">Title</h2>
```

```css
h2 {
  color: black;
}

.card__title {
  color: blue;
}

#title {
  color: red;
}
```

> [!question]- Разбор
> Цвет будет `red`: в этом примере правила конкурируют в одинаковых условиях, а селектор по id специфичнее селекторов класса и тега.

## Задача 6. Cascade

```css
.button {
  color: blue;
}

.button {
  color: green;
}
```

Какой цвет победит?

> [!question]- Разбор
> Цвет будет `green`: у правил одинаковая специфичность, поэтому выигрывает второе — оно записано позже.

## Задача 7. Box model

У элемента:

```css
.box {
  width: 200px;
  padding: 20px;
  border: 2px solid black;
}
```

Какая итоговая ширина при стандартном `content-box`?

> [!question]- Разбор
> `200 + 20 * 2 + 2 * 2 = 244px`. При `box-sizing: border-box` итоговая ширина была бы `200px`.

## Задача 8. Flexbox layout

Сделай toolbar: слева заголовок, справа две кнопки.

> [!question]- Разбор
> ```css
> .toolbar {
>   display: flex;
>   align-items: center;
>   justify-content: space-between;
>   gap: 12px;
> }
>
> .toolbar__actions {
>   display: flex;
>   gap: 8px;
> }
> ```

## Задача 9. Grid layout

Сделай responsive cards без media query.

> [!question]- Разбор
> ```css
> .cards {
>   display: grid;
>   grid-template-columns: repeat(auto-fit, minmax(min(100%, 240px), 1fr));
>   gap: 16px;
> }
> ```

## Задача 10. Responsive layout

Почему фиксированная ширина `width: 1200px` у основного контейнера плоха?

> [!question]- Разбор
> На маленьких экранах появится горизонтальная прокрутка. Лучше:
>
> ```css
> .container {
>   width: min(100% - 32px, 1200px);
>   margin-inline: auto;
> }
> ```

## Задача 11. z-index и stacking context

Tooltip с `z-index: 9999` не перекрывает соседний блок. Что проверить?

> [!question]- Разбор
> Проверь родителей tooltip: `transform`, `opacity < 1`, `filter`, `position` + `z-index` и `isolation` могут создать вложенный stacking context ниже соседнего. Отдельная причина — обрезание через `overflow`; увеличение `z-index` его не отменяет.

## Задача 12. CSS variables

Сделай тему кнопки через CSS variable.

> [!question]- Разбор
> ```css
> :root {
>   --button-bg: #0b72ff;
> }
>
> .button {
>   background: var(--button-bg);
> }
>
> .theme-danger {
>   --button-bg: #d92d20;
> }
> ```

## Задача 13. Pseudo-classes

Добавь индикатор через `:focus-visible`, чтобы браузер показывал его, когда считает фокус полезным для пользователя. Клавиатурная навигация — основной пример, но селектор не является точной проверкой способа ввода.

> [!question]- Разбор
> ```css
> .button:focus-visible {
>   outline: 2px solid currentColor;
>   outline-offset: 2px;
> }
> ```

## Задача 14. Pseudo-elements

Добавь декоративную стрелку после ссылки.

> [!question]- Разбор
> ```css
> .link::after {
>   content: ' ->';
> }
> ```
>
> Если стрелка несет смысл, лучше добавить её в текст или доступное имя, а не только в декоративный pseudo-element.
