# typeof, NaN и Object.is

> [!summary]
> `typeof` помогает быстро отличить базовые типы, но у него есть исторические особенности. Для `NaN` и `-0` иногда нужен `Object.is()`.

## `typeof`

```js
console.log(typeof undefined);
console.log(typeof true);
console.log(typeof 10);
console.log(typeof 10n);
console.log(typeof 'text');
console.log(typeof Symbol('id'));
console.log(typeof {});
console.log(typeof function () {});
```

Результат:

```text
undefined
boolean
number
bigint
string
symbol
object
function
```

`typeof` возвращает строку. Для функций возвращается `'function'`, хотя функции тоже являются объектами.

## `typeof null`

```js
console.log(typeof null);
```

Результат:

```text
object
```

Это историческая особенность языка. На практике `null` нужно проверять отдельно:

```js
if (value === null) {
  // value точно null
}
```

## `NaN`

`NaN` означает "not a number", но его тип - `number`.

```js
console.log(typeof NaN);
console.log(NaN === NaN);
```

Результат:

```text
number
false
```

Для проверки используй `Number.isNaN(value)`.

```js
console.log(Number.isNaN(NaN));
console.log(Number.isNaN('text'));
```

Результат:

```text
true
false
```

## `Object.is()`

`Object.is()` почти похож на строгое сравнение, но иначе обрабатывает `NaN` и `-0`.

```js
console.log(Object.is(NaN, NaN));
console.log(Object.is(0, -0));

console.log(NaN === NaN);
console.log(0 === -0);
```

Результат:

```text
true
false
false
true
```

## Частые ошибки

- Проверять `null` через `typeof`.
- Использовать глобальный `isNaN()` там, где нужен `Number.isNaN()`.
- Забывать, что массивы дают `typeof [] === 'object'`.
- Думать, что `Object.is()` всегда просто синоним `===`.

## Как ответить на собеседовании за одну минуту

`typeof` возвращает строку с типом значения и полезен для быстрых проверок примитивов. Его главная ловушка - `typeof null === 'object'`, поэтому `null` проверяют через `value === null`. `NaN` имеет тип `number` и не равен самому себе, поэтому для точной проверки лучше использовать `Number.isNaN()`. `Object.is()` отличается от `===` в случаях `NaN` и `-0`.
