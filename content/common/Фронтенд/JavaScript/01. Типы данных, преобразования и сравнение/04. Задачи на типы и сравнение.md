# Задачи на типы и сравнение

## 1. `typeof null`

```js
console.log(typeof null);
console.log(null === null);
```

> [!question]- Разбор
> Вывод:
>
> ```text
> object
> true
> ```
>
> `typeof null` - историческая особенность. Само значение `null` при строгом сравнении равно самому себе.

## 2. Массив и объект

```js
console.log(typeof []);
console.log(Array.isArray([]));
```

> [!question]- Разбор
> Вывод:
>
> ```text
> object
> true
> ```
>
> Массив - объект, поэтому `typeof` возвращает `'object'`. Для проверки массива используй `Array.isArray()`.

## 3. `NaN`

```js
console.log(NaN === NaN);
console.log(Number.isNaN(NaN));
```

> [!question]- Разбор
> Вывод:
>
> ```text
> false
> true
> ```
>
> `NaN` не равен самому себе. `Number.isNaN()` проверяет именно `NaN`.

## 4. Truthy/falsy

```js
console.log(Boolean([]));
console.log(Boolean({}));
console.log(Boolean(''));
console.log(Boolean('0'));
```

> [!question]- Разбор
> Вывод:
>
> ```text
> true
> true
> false
> true
> ```
>
> Пустые массивы и объекты truthy. Пустая строка falsy, строка `'0'` truthy.

## 5. Строгое и нестрогое сравнение

```js
console.log(1 == '1');
console.log(1 === '1');
```

> [!question]- Разбор
> Вывод:
>
> ```text
> true
> false
> ```
>
> `==` приводит типы, `===` сравнивает без приведения.

## 6. Объекты по ссылке

```js
console.log({ a: 1 } === { a: 1 });

const user = { a: 1 };
const sameUser = user;

console.log(user === sameUser);
```

> [!question]- Разбор
> Вывод:
>
> ```text
> false
> true
> ```
>
> Два литерала создают два объекта. `sameUser` хранит ссылку на тот же объект.

## 7. `Object.is`

```js
console.log(Object.is(NaN, NaN));
console.log(Object.is(0, -0));
console.log(0 === -0);
```

> [!question]- Разбор
> Вывод:
>
> ```text
> true
> false
> true
> ```
>
> `Object.is()` различает `0` и `-0`, но считает `NaN` равным `NaN`.

## 8. Преобразование к number

```js
console.log(Number(''));
console.log(Number('  '));
console.log(Number('abc'));
```

> [!question]- Разбор
> Вывод:
>
> ```text
> 0
> 0
> NaN
> ```
>
> Пустая строка и строка из пробелов превращаются в `0`. Нечисловая строка дает `NaN`.
