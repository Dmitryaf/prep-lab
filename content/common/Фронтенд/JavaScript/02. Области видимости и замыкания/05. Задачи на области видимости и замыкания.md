# Задачи на области видимости и замыкания

> [!summary]
> Практикум тренирует чтение кода без запуска: scope, shadowing, hoisting, TDZ, Function Declaration, Function Expression и замыкания.

## 1. Глобальная и локальная переменная

```js
const value = 'global';

function run() {
  const value = 'local';
  console.log(value);
}

run();
console.log(value);
```

> [!question]- Разбор
> Вывод:
>
> ```text
> local
> global
> ```
>
> Внутри `run` ближайшая переменная `value` - локальная. После завершения `run` внешний `console.log` читает глобальную `value`.

## 2. Lexical scope

```js
const value = 'global';

function printValue() {
  console.log(value);
}

function run() {
  const value = 'local';
  printValue();
}

run();
```

> [!question]- Разбор
> Вывод:
>
> ```text
> global
> ```
>
> `printValue` объявлена в глобальной области. Место вызова внутри `run` не меняет ее lexical scope.

## 3. Shadowing

```js
let count = 1;

{
  let count = 2;
  console.log(count);
}

console.log(count);
```

> [!question]- Разбор
> Вывод:
>
> ```text
> 2
> 1
> ```
>
> Внутренний `count` скрывает внешний только внутри блока.

## 4. Блочная область видимости

```js
if (true) {
  const message = 'ready';
}

console.log(message);
```

> [!question]- Разбор
> Будет `ReferenceError`. `message` объявлена через `const` внутри блока `if` и недоступна снаружи.

## 5. `var` до объявления

```js
console.log(score);
var score = 10;
console.log(score);
```

> [!question]- Разбор
> Вывод:
>
> ```text
> undefined
> 10
> ```
>
> Binding для `var score` создан заранее и инициализирован `undefined`. Присваивание `10` происходит на второй строке.

## 6. `let` до объявления

```js
console.log(score);
let score = 10;
```

> [!question]- Разбор
> Будет `ReferenceError`. `score` находится в TDZ до выполнения строки `let score = 10`.

## 7. Function Declaration

```js
sayHi();

function sayHi() {
  console.log('Hi');
}
```

> [!question]- Разбор
> Вывод:
>
> ```text
> Hi
> ```
>
> Function Declaration создает callable binding до выполнения строк тела области видимости.

## 8. Function Expression

```js
sayHi();

const sayHi = function () {
  console.log('Hi');
};
```

> [!question]- Разбор
> Будет `ReferenceError`. `sayHi` объявлена через `const`, поэтому до инициализации находится в TDZ. Function Expression будет создана только при выполнении строки присваивания.

## 9. Базовое замыкание

```js
function outer() {
  const message = 'closed';

  return function inner() {
    console.log(message);
  };
}

const fn = outer();
fn();
```

> [!question]- Разбор
> Вывод:
>
> ```text
> closed
> ```
>
> `inner` сохраняет доступ к переменной `message` из области вызова `outer`.

## 10. Изменение внешней переменной

```js
function createLogger() {
  let value = 1;

  const log = function () {
    console.log(value);
  };

  value = 2;
  return log;
}

const log = createLogger();
log();
```

> [!question]- Разбор
> Вывод:
>
> ```text
> 2
> ```
>
> Замыкание не копирует `1`. Функция сохраняет доступ к переменной `value`, а переменная перед возвратом функции была изменена.

## 11. Счетчик через замыкание

```js
function createCounter() {
  let count = 0;

  return function () {
    count += 1;
    console.log(count);
  };
}

const counter = createCounter();
counter();
counter();
```

> [!question]- Разбор
> Вывод:
>
> ```text
> 1
> 2
> ```
>
> Оба вызова работают с одной переменной `count`, сохраненной в замыкании.

## 12. Цикл с `var`

```js
const callbacks = [];

for (var i = 0; i < 3; i += 1) {
  callbacks.push(function () {
    console.log(i);
  });
}

callbacks[0]();
callbacks[1]();
callbacks[2]();
```

> [!question]- Разбор
> Вывод:
>
> ```text
> 3
> 3
> 3
> ```
>
> `var i` - одна переменная на весь цикл. После завершения цикла ее значение равно `3`, и все функции читают именно ее.

## 13. Цикл с `let`

```js
const callbacks = [];

for (let i = 0; i < 3; i += 1) {
  callbacks.push(function () {
    console.log(i);
  });
}

callbacks[0]();
callbacks[1]();
callbacks[2]();
```

> [!question]- Разбор
> Вывод:
>
> ```text
> 0
> 1
> 2
> ```
>
> В цикле с `let` каждая итерация получает отдельную переменную `i`. Каждая функция закрывает переменную своей итерации.

## 14. Практическое применение closure

Напиши функцию `createOnce`, которая принимает функцию `fn` и возвращает новую функцию. Новая функция вызывает `fn` только один раз, а последующие вызовы возвращают первый результат.

```js
function createOnce(fn) {
  // твой код
}

const init = createOnce(function () {
  console.log('init');
  return 42;
});

console.log(init());
console.log(init());
```

> [!question]- Разбор
> Один из вариантов:
>
> ```js
> function createOnce(fn) {
>   let called = false;
>   let result;
>
>   return function once() {
>     if (!called) {
>       called = true;
>       result = fn();
>     }
>
>     return result;
>   };
> }
> ```
>
> `called` и `result` живут во внешней области `createOnce`. Возвращенная функция сохраняет к ним доступ и использует их как приватное состояние.
