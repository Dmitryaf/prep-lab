# Контекст this

> [!summary]
> `this` в JavaScript помогает функции работать с объектом, для которого она вызвана. Для обычной функции главное правило практического уровня: `this` определяется способом вызова. У стрелочной функции собственного `this` нет.

- почему `this` у обычной функции нельзя определить только по месту объявления;
- чем вызов `obj.method()` отличается от `fn()`;
- почему метод теряет объект при присваивании в переменную или передаче callback;
- как `call()`, `apply()` и `bind()` явно управляют `this`;
- почему стрелочная функция не получает свой `this`;
- как `new` создает объект и передает его в конструктор как `this`;

## Быстрое повторение перед собеседованием

- Обычная функция: смотри на способ вызова.
- `obj.method()` обычно дает `this === obj`.
- `const fn = obj.method; fn()` теряет объект слева от точки.
- В strict mode самостоятельный вызов дает `this === undefined`.
- В нестрогом режиме `undefined`/`null` для `this` заменяются глобальным объектом.
- `call()` и `apply()` вызывают функцию сразу.
- `bind()` возвращает новую функцию с заранее заданным `this`.
- Стрелочная функция не имеет собственного `this`.
- Стрелка в object literal не становится методом с `this === object`.
- `new Constructor()` создает объект и вызывает конструктор с этим объектом как `this`.
