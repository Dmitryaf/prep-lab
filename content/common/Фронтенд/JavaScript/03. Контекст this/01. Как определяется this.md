# Как определяется this

> [!summary]
> У обычной функции `this` определяется способом вызова. Одна и та же функция может получить разные значения `this`, если ее вызвать как метод разных объектов, самостоятельно или через `call()`, `apply()`, `bind()` и `new`.

## Зачем понимать this

`this` часто встречается в методах объектов, классах, обработчиках событий, callback-функциях и задачах на вывод. На собеседовании обычно проверяют не терминологию спецификации, а умение увидеть, что именно стоит слева от вызова функции.

Главная ловушка: обычная функция не запоминает объект, внутри которого она была написана. Она получает `this` в момент вызова.

## Базовая модель

Для обычной функции:

1. Если функция вызвана как метод объекта: `obj.method()`, то `this` обычно равен объекту слева от точки.
2. Если функция вызвана самостоятельно: `fn()`, то значение `this` зависит от strict mode.
3. Если функция вызвана через `call()`, `apply()` или функцию, созданную `bind()`, `this` задается явно.
4. Если функция вызвана через `new`, создается новый объект, и он становится `this`.

Стрелочные функции живут по другому правилу: собственного `this` у них нет. Они используют `this` окружающего контекста. Это разбирается в [[Фронтенд/JavaScript/03. Контекст this/04. Стрелочные функции и lexical this|Стрелочные функции и lexical this]].

## this и lexical scope

`lexical scope` определяет, где функция ищет переменные. Он зависит от места объявления функции.

`this` у обычной функции зависит не от места объявления, а от способа вызова.

```js
const name = 'Global';

function showName() {
  console.log(this.name);
}

const user = {
  name: 'Alex',
  showName,
};

user.showName(); // Alex
```

Функция `showName` объявлена отдельно от объекта `user`, но при вызове `user.showName()` получает `this === user`.

## Вызов метода объекта

```js
const user = {
  name: 'Alex',
  showName() {
    console.log(this.name);
  },
};

user.showName(); // Alex
```

Вызов имеет форму `user.showName()`. Объект слева от точки становится `this` для обычной функции `showName`.

Важно: привязка происходит именно в момент вызова. Метод не получает вечную связь с объектом.

## Одна функция как метод разных объектов

```js
function showName() {
  console.log(this.name);
}

const firstUser = {
  name: 'Alex',
  showName,
};

const secondUser = {
  name: 'Maria',
  showName,
};

firstUser.showName(); // Alex
secondUser.showName(); // Maria
```

Функция одна и та же. Но первый вызов идет через `firstUser`, второй через `secondUser`, поэтому `this` разный.

## Самостоятельный вызов функции

```js
'use strict';

function showThis() {
  console.log(this);
}

showThis(); // undefined
```

В strict mode самостоятельный вызов обычной функции не подставляет глобальный объект. Поэтому `this` будет `undefined`.

В нестрогом режиме при самостоятельном вызове `this` обычно станет глобальным объектом. В обычном скрипте браузера это `window`, но в современных проектах часто используются модули, сборщики и строгий режим, поэтому на собеседовании лучше всегда уточнять условия.

## Вложенная обычная функция внутри метода

```js
'use strict';

const user = {
  name: 'Alex',
  showName() {
    function inner() {
      console.log(this);
    }

    inner();
  },
};

user.showName(); // undefined
```

`showName()` вызван как метод, поэтому внутри него `this === user`.

Но `inner()` вызвана самостоятельно. Для обычной функции это новый вызов со своим `this`. В strict mode он дает `undefined`.

Если нужно использовать `this` внешнего метода, часто применяют стрелочную функцию:

```js
const user = {
  name: 'Alex',
  showName() {
    const inner = () => {
      console.log(this.name);
    };

    inner();
  },
};

user.showName(); // Alex
```

## Краткое дерево решений

```text
Это стрелочная функция?
  Да -> своего this нет, используется this снаружи.
  Нет -> смотри на вызов:
    new Fn() -> this это новый объект.
    fn.call(obj) / fn.apply(obj) / boundFn() -> this задан явно.
    obj.method() -> this обычно obj.
    fn() -> strict: undefined; non-strict: глобальный объект.
```

## Частые ошибки

- Определять `this` по месту объявления обычной функции.
- Считать, что метод навсегда привязан к объекту.
- Забывать про strict mode при самостоятельном вызове.
- Думать, что вложенная обычная функция внутри метода автоматически получает тот же `this`.
- Смешивать `this` и lexical scope.

## Как ответить на собеседовании за одну минуту

У обычной функции `this` определяется способом вызова. Если вызвать функцию как `obj.method()`, то `this` обычно будет объектом слева от точки. Если сохранить метод в переменную и вызвать как `fn()`, объект потеряется; в строгом режиме `this` будет `undefined`, в нестрогом режиме может стать глобальным объектом. Одна и та же функция может быть методом разных объектов и получать разный `this`. Стрелочные функции отличаются: у них нет собственного `this`, они берут его из окружающего контекста.

> [!note]- Углубление: strict mode и глобальный объект
> В нестрогом режиме при вызове обычной функции с `this` равным `undefined` или `null` применяется подстановка глобального объекта. В обычном скрипте браузера глобальный объект доступен как `window`.
>
> В strict mode такой подстановки нет: `this` остается тем значением, с которым функция была вызвана. Поэтому самостоятельный вызов `fn()` дает `undefined`.
>
> На верхнем уровне `this` зависит от формы кода и среды выполнения. В обычном скрипте браузера на верхнем уровне `this` обычно равен `globalThis`/`window`. В ES-модуле на верхнем уровне `this` равен `undefined`. В Node.js и сборщиках могут быть дополнительные обертки, поэтому для задач нужно явно задавать условия.

> [!note]- Углубление: терминология спецификации
> На уровне ECMAScript точная модель сложнее правила "объект слева от точки".
>
> При вычислении выражения вызова спецификация работает с внутренним представлением ссылки на значение. Для некоторых выражений эта ссылка содержит не только функцию, но и базовое значение, от которого функция была получена.
>
> `Reference Record` - спецификационная структура, которая может хранить базу обращения, например объект в `obj.method`.
>
> `GetThisValue` получает значение, которое нужно передать как `this`, из такой ссылки.
>
> `OrdinaryCallBindThis` связывает вычисленное значение `this` с выполнением обычной функции с учетом режима функции: lexical, strict или global.
>
> Для P0 важно не заучивать эти названия, а понимать практическое следствие: `this` обычной функции определяется формой вызова, а не местом объявления функции.

## Практические задачи

```js

function showName() {
  console.log(this.name);
}

const user = { name: 'Alex', showName };
user.showName();
```

2. Объясни вывод:

```js
'use strict';

const user = {
  name: 'Alex',
  showName() {
    function inner() {
      console.log(this);
    }

    inner();
  },
};

user.showName();
```

3. Перепиши вторую задачу так, чтобы вложенная функция вывела `Alex`.
