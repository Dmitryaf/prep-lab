# call, apply и bind

> [!summary]
> `call()`, `apply()` и `bind()` позволяют явно управлять `this` обычной функции. `call()` и `apply()` вызывают функцию сразу, а `bind()` создает новую функцию с заранее заданным `this`.

## Зачем явно задавать this

Иногда функция написана отдельно, но должна выполниться для конкретного объекта. Еще чаще метод потерял контекст после передачи callback. В таких случаях можно явно сказать, чему должен быть равен `this`.

```js
function showName() {
  console.log(this.name);
}

const user = { name: 'Alex' };

showName.call(user); // Alex
```

## call()

`call(thisArg, arg1, arg2, ...)` вызывает функцию сразу.

```js
function introduce(role) {
  console.log(`${this.name}: ${role}`);
}

const user = { name: 'Alex' };

introduce.call(user, 'frontend developer'); // Alex: frontend developer
```

Первый аргумент - значение `this`. Остальные аргументы передаются в функцию обычным списком.

## apply()

`apply(thisArg, argsArray)` тоже вызывает функцию сразу, но принимает аргументы массивом или array-like объектом.

```js
function introduce(role, level) {
  console.log(`${this.name}: ${role}, ${level}`);
}

const user = { name: 'Alex' };

introduce.apply(user, ['frontend developer', 'middle']); // Alex: frontend developer, middle
```

Главное отличие от `call()` - форма передачи аргументов.

## bind()

`bind(thisArg, arg1, arg2, ...)` не вызывает функцию сразу. Он возвращает новую функцию.

```js
function introduce(role) {
  console.log(`${this.name}: ${role}`);
}

const user = { name: 'Alex' };
const introduceAlex = introduce.bind(user);

introduceAlex('frontend developer'); // Alex: frontend developer
```

Новая функция запоминает `thisArg`. Ее можно передать callback, и она не потеряет `this`.

## Решение проблемы потерянного контекста

```js
const user = {
  name: 'Alex',
  showName() {
    console.log(this.name);
  },
};

const showName = user.showName.bind(user);

showName(); // Alex
setTimeout(showName, 0); // Alex
```

`bind()` удобен, когда один и тот же привязанный callback нужно переиспользовать несколько раз.

## Частичное применение аргументов через bind

`bind()` может заранее зафиксировать не только `this`, но и первые аргументы.

```js
function multiply(a, b) {
  return a * b;
}

const double = multiply.bind(null, 2);

console.log(double(5)); // 10
```

Здесь `this` не важен, поэтому передан `null`. Первый аргумент `a` заранее равен `2`, а `b` приходит при вызове `double(5)`.

## Сравнительная таблица

| Метод | Вызывает сразу | Как передает аргументы | Что возвращает |
|---|---:|---|---|
| `call(thisArg, arg1, arg2)` | Да | Списком | Результат функции |
| `apply(thisArg, argsArray)` | Да | Массивом или array-like | Результат функции |
| `bind(thisArg, arg1, arg2)` | Нет | Фиксирует первые аргументы | Новую функцию |

## Типичные сценарии

- Вызвать функцию для конкретного объекта без добавления метода в объект.
- Починить потерянный контекст метода.
- Передать метод как callback.
- Создать функцию с заранее заданными первыми аргументами.
- Переиспользовать функцию для похожих объектов.

## Частые ошибки

- Ожидать, что `bind()` вызовет функцию сразу.
- Передавать в `apply()` аргументы списком вместо массива.
- Использовать `call()`/`apply()`/`bind()` со стрелочной функцией и ожидать изменения `this`.
- Делать повторный `bind()` и ждать, что он заменит первый `this`.
- Забывать, что в нестрогом режиме `null` и `undefined` как `thisArg` могут быть заменены глобальным объектом.

## Как ответить на собеседовании за одну минуту

`call()`, `apply()` и `bind()` нужны, чтобы явно управлять `this`. `call()` вызывает функцию сразу и принимает аргументы списком. `apply()` тоже вызывает сразу, но принимает аргументы массивом. `bind()` не вызывает функцию, а возвращает новую функцию с заранее заданным `this` и, при необходимости, первыми аргументами. Это часто используют, чтобы не потерять контекст при передаче метода как callback.

> [!note]- Углубление: повторный bind и вызов bound function через new
> Если функция уже создана через `bind()`, повторный `bind()` не заменит сохраненный `this`.
>
> ```js
> function showName() {
>   console.log(this.name);
> }
>
> const first = { name: 'Alex' };
> const second = { name: 'Maria' };
>
> const bound = showName.bind(first);
> const rebound = bound.bind(second);
>
> rebound(); // Alex
> ```
>
> Дополнительные аргументы при повторном `bind()` могут добавляться к списку заранее сохраненных аргументов.
>
> Если bound function вызывается через `new`, сохраненный `thisArg` игнорируется: `this` должен быть новым создаваемым объектом. Это редкий edge case; для P0 достаточно помнить, что `bind()` фиксирует `this` для обычных вызовов, но `new` имеет отдельное поведение.

## Практические задачи

1. Перепиши вызов с `call()` на `apply()`:

```js
function sum(a, b) {
  return this.base + a + b;
}

const context = { base: 10 };

console.log(sum.call(context, 1, 2)); // 13
```

2. Исправь потерю контекста через `bind()`:

```js
const user = {
  name: 'Alex',
  showName() {
    console.log(this.name);
  },
};

setTimeout(user.showName, 0);
```

3. Что выведет код?

```js
function join(a, b, c) {
  return `${this.prefix}:${a}-${b}-${c}`;
}

const fn = join.bind({ prefix: 'id' }, 1);

console.log(fn(2, 3));
```
