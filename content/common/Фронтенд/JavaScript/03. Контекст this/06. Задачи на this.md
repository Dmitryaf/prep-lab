# Задачи на this

> [!summary]
> Практикум проверяет главную модель: у обычной функции `this` определяется способом вызова, у стрелочной функции собственного `this` нет, а `new` создает новый объект и делает его `this`.

## Как решать задачи

1. Сначала отметь, обычная это функция или стрелочная.
2. Для обычной функции смотри на форму вызова: `obj.method()`, `fn()`, `call/apply/bind`, `new`.
3. Для самостоятельного вызова учитывай strict mode.
4. Для callback уточняй, как конкретный API вызывает функцию.
5. Для стрелки ищи внешний `this`.

## Задача 1. Самостоятельный вызов

Условия: strict mode.

```js
'use strict';

function showThis() {
  console.log(this);
}

showThis();
```

> [!question]- Разбор
> Вывод:
>
> ```text
> undefined
> ```
>
> `showThis()` вызвана самостоятельно. В strict mode обычная функция при самостоятельном вызове получает `this === undefined`.

## Задача 2. Метод объекта

```js
const user = {
  name: 'Alex',
  showName() {
    console.log(this.name);
  },
};

user.showName();
```

> [!question]- Разбор
> Вывод:
>
> ```text
> Alex
> ```
>
> Вызов имеет форму `user.showName()`. Для обычного метода `this` обычно равен объекту слева от точки, то есть `user`.

## Задача 3. Одна функция как метод двух объектов

```js
function showName() {
  console.log(this.name);
}

const firstUser = {
  name: 'Alex',
  showName,
};

const secondUser = {
  name: 'Maria',
  showName,
};

firstUser.showName();
secondUser.showName();
```

> [!question]- Разбор
> Вывод:
>
> ```text
> Alex
> Maria
> ```
>
> Функция одна и та же, но вызовы разные. В первом случае слева от точки `firstUser`, во втором - `secondUser`.

## Задача 4. Извлечение метода в переменную

Условия: strict mode.

```js
'use strict';

const user = {
  name: 'Alex',
  showName() {
    console.log(this.name);
  },
};

const showName = user.showName;

showName();
```

> [!question]- Разбор
> Результат:
>
> ```text
> TypeError
> ```
>
> Переменная `showName` хранит функцию, но не хранит объект `user`. Вызов стал самостоятельным: `showName()`. В strict mode `this === undefined`, поэтому чтение `this.name` приводит к ошибке.

## Задача 5. Передача метода как callback

Условия: strict mode; `execute` вызывает callback как обычную функцию.

```js
'use strict';

const user = {
  name: 'Alex',
  showName() {
    console.log(this.name);
  },
};

function execute(callback) {
  callback();
}

execute(user.showName);
```

> [!question]- Разбор
> Результат:
>
> ```text
> TypeError
> ```
>
> В `execute` передается функция `user.showName`, но не вызов `user.showName()`. Внутри `execute` callback вызывается как `callback()`, без объекта слева от точки. В strict mode `this === undefined`, поэтому чтение `this.name` приводит к ошибке.

## Задача 6. Исправление wrapper-функцией

```js
const user = {
  name: 'Alex',
  showName() {
    console.log(this.name);
  },
};

setTimeout(() => {
  user.showName();
}, 0);
```

> [!question]- Разбор
> Вывод:
>
> ```text
> Alex
> ```
>
> Callback - стрелочная wrapper-функция. Когда она выполнится, внутри нее будет обычный вызов `user.showName()`. Объект `user` снова стоит слева от точки.

## Задача 7. Исправление через bind

```js
const user = {
  name: 'Alex',
  showName() {
    console.log(this.name);
  },
};

const showName = user.showName.bind(user);

showName();
```

> [!question]- Разбор
> Вывод:
>
> ```text
> Alex
> ```
>
> `bind(user)` создает новую функцию, у которой `this` заранее связан с `user`. Поэтому самостоятельный вызов `showName()` не теряет нужный объект.

## Задача 8. call и apply

```js
function show(role, level) {
  console.log(`${this.name}: ${role}, ${level}`);
}

const user = { name: 'Alex' };

show.call(user, 'frontend', 'middle');
show.apply(user, ['frontend', 'middle']);
```

> [!question]- Разбор
> Вывод:
>
> ```text
> Alex: frontend, middle
> Alex: frontend, middle
> ```
>
> `call()` и `apply()` вызывают функцию сразу и явно задают `this`. Разница только в форме аргументов: список против массива.

## Задача 9. Частичное применение через bind

```js
function createLabel(prefix, value) {
  return `${this.scope}:${prefix}-${value}`;
}

const createUserLabel = createLabel.bind({ scope: 'user' }, 'id');

console.log(createUserLabel(42));
```

> [!question]- Разбор
> Вывод:
>
> ```text
> user:id-42
> ```
>
> `bind()` зафиксировал `this` как `{ scope: 'user' }` и первый аргумент `prefix` как `'id'`. При вызове `createUserLabel(42)` значение `42` становится вторым аргументом.

## Задача 10. Вложенная обычная функция внутри метода

Условия: strict mode.

```js
'use strict';

const user = {
  name: 'Alex',
  showName() {
    function inner() {
      console.log(this.name);
    }

    inner();
  },
};

user.showName();
```

> [!question]- Разбор
> Результат:
>
> ```text
> TypeError
> ```
>
> `showName()` вызван как метод, но `inner()` вызвана самостоятельно. У обычной вложенной функции свой вызов и свой `this`. В strict mode это `undefined`.

## Задача 11. Стрелка внутри метода

```js
const user = {
  name: 'Alex',
  showName() {
    const inner = () => {
      console.log(this.name);
    };

    inner();
  },
};

user.showName();
```

> [!question]- Разбор
> Вывод:
>
> ```text
> Alex
> ```
>
> `showName()` получает `this === user`. Стрелка `inner` не создает собственного `this`, поэтому использует `this` внешнего метода.

## Задача 12. Стрелка как свойство object literal

Условия: ES module.

```js
const user = {
  name: 'Alex',
  showName: () => {
    console.log(this);
  },
};

user.showName();
```

> [!question]- Разбор
> Вывод:
>
> ```text
> undefined
> ```
>
> В ES-модуле на верхнем уровне `this` равен `undefined`. Стрелка не получает `user` как `this`, потому что у нее нет собственного `this`. Она берет внешний `this`.

## Задача 13. Попытка изменить this стрелки через call

Условия: ES module.

```js
const showThis = () => {
  console.log(this);
};

showThis.call({ name: 'Alex' });
```

> [!question]- Разбор
> Вывод:
>
> ```text
> undefined
> ```
>
> `call()` не может назначить стрелочной функции новый `this`. Стрелка использует внешний `this`, который в ES module на верхнем уровне равен `undefined`.

## Задача 14. Функция-конструктор и new

```js
function User(name) {
  this.name = name;
}

const user = new User('Alex');

console.log(user.name);
```

> [!question]- Разбор
> Вывод:
>
> ```text
> Alex
> ```
>
> `new User('Alex')` создает новый объект и вызывает `User` с этим объектом как `this`. Запись `this.name = name` добавляет свойство созданному объекту.

## Задача 15. Конструктор с явным return

```js
function User(name) {
  this.name = name;

  return {
    name: 'Maria',
  };
}

const user = new User('Alex');

console.log(user.name);
```

> [!question]- Разбор
> Вывод:
>
> ```text
> Maria
> ```
>
> Если конструктор явно возвращает объект, результатом `new` становится этот объект. Созданный объект с `name: 'Alex'` не используется как итоговый результат.

## Задача 16. Комбинированная задача

Условия: strict mode.

```js
'use strict';

function showName(label) {
  console.log(`${label}: ${this.name}`);
}

const user = {
  name: 'Alex',
  showName,
  run() {
    const direct = this.showName;
    const bound = this.showName.bind(this, 'bound');

    this.showName('method');
    bound();
    direct.call({ name: 'Maria' }, 'call');
  },
};

user.run();
```

> [!question]- Разбор
> Вывод:
>
> ```text
> method: Alex
> bound: Alex
> call: Maria
> ```
>
> `user.run()` вызывает `run` с `this === user`.
>
> `this.showName('method')` внутри `run` - это метод-вызов через `user`, поэтому выводится `Alex`.
>
> `bound` создан через `bind(this, 'bound')`, где `this` в момент создания равен `user`. Поэтому `bound()` выводит `Alex`.
>
> `direct` хранит исходную функцию без объекта, но вызов `direct.call({ name: 'Maria' }, 'call')` явно задает `this`, поэтому выводится `Maria`.
