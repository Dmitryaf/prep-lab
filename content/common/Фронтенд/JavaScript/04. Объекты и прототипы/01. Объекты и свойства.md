# Объекты и свойства

> [!summary]
> Объект хранит свойства: пары ключ-значение. Ключом обычно является строка или symbol, а значение может быть любым JavaScript-значением.

## Создание объекта

```js
const user = {
  name: 'Alex',
  age: 30,
};
```

Это запись объекта через `{}`. Она удобна для обычных данных, настроек и объектов передачи данных.

## Доступ через точку и скобки

```js
const user = {
  name: 'Alex',
  'home city': 'Prague',
};

console.log(user.name);
console.log(user['home city']);
```

Точка подходит для известных корректных имен. Скобки нужны для динамических ключей и ключей со спецсимволами.

```js
const key = 'name';
console.log(user[key]);
```

## Вычисляемые имена свойств

```js
const field = 'name';

const user = {
  [field]: 'Alex',
};

console.log(user.name);
```

Результат:

```text
Alex
```

## Создание, изменение и удаление

```js
const user = {};

user.name = 'Alex';
user.name = 'Mira';
delete user.name;
```

`delete` удаляет свойство из объекта. В прикладном коде состояние часто обновляют созданием нового объекта, а не `delete`, особенно во frontend-state.

## Собственные и унаследованные свойства

Собственное свойство лежит прямо в объекте. Унаследованное находится выше по цепочке прототипов.

```js
const animal = { eats: true };
const rabbit = Object.create(animal);
rabbit.jumps = true;

console.log(Object.hasOwn(rabbit, 'jumps'));
console.log(Object.hasOwn(rabbit, 'eats'));
console.log('eats' in rabbit);
```

Результат:

```text
true
false
true
```

## `Object.hasOwn()` и `in`

| Проверка | Что проверяет |
| --- | --- |
| `Object.hasOwn(obj, key)` | только собственные свойства |
| `obj.hasOwnProperty(key)` | только собственные, но метод может быть переопределен |
| `key in obj` | собственные и унаследованные |

Для нового кода обычно удобнее `Object.hasOwn(obj, key)`.

## Перебор свойств

```js
const user = {
  name: 'Alex',
  age: 30,
};

console.log(Object.keys(user));
console.log(Object.values(user));
for (const [key, value] of Object.entries(user)) {
  console.log(`${key}: ${value}`);
}
```

Результат:

```text
['name', 'age']
['Alex', 30]
name: Alex
age: 30
```

`Object.keys()`, `Object.values()` и `Object.entries()` учитывают только собственные свойства со строковыми ключами и включённым флагом `enumerable`. Флаг означает, что свойство участвует в таком переборе.

`for...in` перебирает перечисляемые свойства со строковыми ключами, включая унаследованные.

```js
const proto = { inherited: true };
const obj = Object.create(proto);
obj.own = true;

for (const key in obj) {
  console.log(key);
}
```

Результат:

```text
own
inherited
```

Если нужны только собственные свойства, добавляй проверку:

```js
for (const key in obj) {
  if (Object.hasOwn(obj, key)) {
    console.log(key);
  }
}
```

## Частые ошибки

- Думать, что `Object.keys()` возвращает унаследованные свойства.
- Думать, что `for...in` перебирает только собственные свойства.
- Использовать `obj.hasOwnProperty()` на объекте, где этот метод может отсутствовать или быть переопределен.
- Путать отсутствие свойства и значение `undefined`.

## Как ответить на собеседовании за одну минуту

Объект хранит свойства. Свойство может быть собственным или найденным в прототипе. Через точку обращаются к известному имени, через квадратные скобки - к динамическому или нестандартному ключу. `Object.hasOwn()` проверяет только собственные свойства, а `in` проверяет всю цепочку прототипов. `Object.keys()`, `values()` и `entries()` учитывают собственные перечисляемые свойства со строковыми ключами, а `for...in` проходит и по унаследованным.

- Почему `in` может вернуть `true`, когда `Object.hasOwn()` возвращает `false`?
