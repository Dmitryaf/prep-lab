# prototype функций-конструкторов

> [!summary]
> У обычной функции может быть свойство `.prototype`. Когда функцию вызывают через `new`, создаваемый объект связывается с этим `.prototype`.

## `.prototype` функции и прототип объекта

Это разные вещи:

- `Constructor.prototype` - обычное свойство функции;
- прототип объекта - внутренняя ссылка объекта на другой объект или `null`.

```js
function User(name) {
  this.name = name;
}

User.prototype.sayHi = function () {
  return `Hi, ${this.name}`;
};

const user = new User('Alex');

console.log(Object.getPrototypeOf(user) === User.prototype);
console.log(user.sayHi());
```

Результат:

```text
true
Hi, Alex
```

## Что делает `new`

Подробный разбор `new` есть в [[Фронтенд/JavaScript/03. Контекст this/05. Конструкторы и оператор new|Конструкторы и оператор new]]. Для прототипов важно одно: `new User()` создает объект, чей прототип связан с `User.prototype`.

## Методы в прототипе

Метод в прототипе не копируется в каждый экземпляр.

```js
function Counter() {
  this.value = 0;
}

Counter.prototype.increment = function () {
  this.value += 1;
};

const first = new Counter();
const second = new Counter();

console.log(first.increment === second.increment);
```

Результат:

```text
true
```

Оба объекта находят один и тот же метод в `Counter.prototype`.

## Замена `.prototype`

Если заменить `Constructor.prototype`, новые экземпляры получат новую связь, а старые останутся со старым прототипом.

```js
function User() {}

const first = new User();

User.prototype = {
  sayHi() {
    return 'hi';
  },
};

const second = new User();

console.log('sayHi' in first);
console.log('sayHi' in second);
```

Результат:

```text
false
true
```

## Частые ошибки

- Говорить, что `prototype` - это прототип функции. Это свойство функции, которое используется для будущих экземпляров.
- Думать, что методы object literal автоматически хранятся в прототипе.
- Думать, что `new` только создает пустой объект. Он еще связывает объект с `Constructor.prototype` и вызывает конструктор с этим объектом как `this`.
- Забывать, что стрелочные функции нельзя использовать как конструкторы.

## Как ответить на собеседовании за одну минуту

У функции-конструктора есть свойство `.prototype`. Когда функцию вызывают через `new`, новый объект получает внутренний прототип, равный `Constructor.prototype`. Поэтому методы, добавленные в `Constructor.prototype`, доступны всем экземплярам через цепочку прототипов и не копируются в каждый объект. `.prototype` функции и прототип конкретного объекта - связанные, но разные вещи.
