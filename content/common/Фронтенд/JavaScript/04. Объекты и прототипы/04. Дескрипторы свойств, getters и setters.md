# Дескрипторы свойств, getters и setters

> [!summary]
> Дескриптор описывает не только значение свойства, но и его атрибуты: можно ли менять значение, перечислять свойство и перенастраивать его.

## Data descriptor

```js
const user = {};

Object.defineProperty(user, 'name', {
  value: 'Alex',
  writable: true,
  enumerable: true,
  configurable: true,
});

console.log(user.name);
```

Атрибуты:

- `writable` - можно ли менять значение;
- `enumerable` - попадает ли свойство в `Object.keys()` и `for...in`;
- `configurable` - можно ли перенастроить или удалить свойство.

## `Object.getOwnPropertyDescriptor()`

```js
const user = { name: 'Alex' };

console.log(Object.getOwnPropertyDescriptor(user, 'name'));
```

У обычного свойства, созданного в записи объекта через `{}`, флаги `writable`, `enumerable` и `configurable` по умолчанию включены.

## Неперечисляемое свойство

```js
const user = {};

Object.defineProperty(user, 'id', {
  value: 1,
  enumerable: false,
});

console.log(user.id);
console.log(Object.keys(user));
```

Результат:

```text
1
[]
```

## Getters и setters

Свойство может вызывать функции вместо хранения готового значения: при чтении запускается getter, при записи — setter. Такое свойство называют accessor property; обычного поля `value` в его дескрипторе нет.

```js
const user = {
  firstName: 'Alex',
  lastName: 'Stone',

  get fullName() {
    return `${this.firstName} ${this.lastName}`;
  },

  set fullName(value) {
    const [firstName, lastName] = value.split(' ');
    this.firstName = firstName;
    this.lastName = lastName;
  },
};

console.log(user.fullName);
user.fullName = 'Mira Fox';
console.log(user.firstName);
```

Результат:

```text
Alex Stone
Mira
```

## Частые ошибки

- Думать, что getter хранит обычное значение. Getter вычисляет значение при чтении.
- При создании нового свойства через `Object.defineProperty()` пропущенные флаги `writable`, `enumerable`, `configurable` равны `false`. При изменении уже существующего свойства неуказанные атрибуты сохраняются. Например, после `Object.defineProperty({ x: 1 }, 'x', { value: 2 })` свойство `x` остаётся перечисляемым и доступным для записи.
- Считать дескрипторы темой только для библиотек. На собеседованиях они часто появляются рядом с enumerability, getters и setters.

## Как ответить на собеседовании за одну минуту

Дескриптор свойства описывает, как свойство ведет себя: его значение, можно ли его менять, перечислять и конфигурировать. `Object.getOwnPropertyDescriptor()` читает дескриптор, `Object.defineProperty()` создает или меняет свойство с нужными атрибутами. Свойство с getter и setter вызывает функции: `get` при чтении, `set` при записи. Например, getter может каждый раз вычислять значение из других полей.

> [!note]- Углубление: data и accessor descriptors
> В спецификации есть два основных вида дескрипторов: data descriptor с `value`/`writable` и accessor descriptor с `get`/`set`. Один и тот же дескриптор не должен одновременно описывать обычное значение и accessor-функции.
