# Задачи на объекты и прототипы

## 1. Точка и скобки

```js
const key = 'name';
const user = { name: 'Alex' };

console.log(user.key);
console.log(user[key]);
```

> [!question]- Разбор
> Вывод:
>
> ```text
> undefined
> Alex
> ```
>
> `user.key` ищет свойство с именем `'key'`. `user[key]` сначала вычисляет переменную `key`, затем ищет `'name'`.

## 2. `in` и `Object.hasOwn`

```js
const proto = { role: 'guest' };
const user = Object.create(proto);
user.name = 'Alex';

console.log(Object.hasOwn(user, 'role'));
console.log('role' in user);
```

> [!question]- Разбор
> Вывод:
>
> ```text
> false
> true
> ```
>
> `role` унаследован из прототипа. `Object.hasOwn()` проверяет только сам объект, `in` проверяет всю цепочку.

## 3. `Object.keys()` и `for...in`

```js
const proto = { inherited: 1 };
const obj = Object.create(proto);
obj.own = 2;

console.log(Object.keys(obj));

for (const key in obj) {
  console.log(key);
}
```

> [!question]- Разбор
> Вывод:
>
> ```text
> ['own']
> own
> inherited
> ```
>
> `Object.keys()` возвращает собственные enumerable string-свойства. `for...in` проходит и по унаследованным enumerable-свойствам.

## 4. Shadowing

```js
const proto = { value: 1 };
const obj = Object.create(proto);

console.log(obj.value);
obj.value = 2;
console.log(obj.value);
console.log(proto.value);
```

> [!question]- Разбор
> Вывод:
>
> ```text
> 1
> 2
> 1
> ```
>
> Присваивание создает собственное свойство `value` на `obj`, которое скрывает свойство прототипа.

## 5. Методы в прототипе

```js
function User(name) {
  this.name = name;
}

User.prototype.sayHi = function () {
  return this.name;
};

const first = new User('Alex');
const second = new User('Mira');

console.log(first.sayHi === second.sayHi);
console.log(second.sayHi());
```

> [!question]- Разбор
> Вывод:
>
> ```text
> true
> Mira
> ```
>
> Метод один и лежит в `User.prototype`. При вызове `second.sayHi()` значение `this` равно `second`.

## 6. Дескриптор

```js
const obj = {};

Object.defineProperty(obj, 'hidden', {
  value: 1,
  enumerable: false,
});

console.log(obj.hidden);
console.log(Object.keys(obj));
```

> [!question]- Разбор
> Вывод:
>
> ```text
> 1
> []
> ```
>
> Свойство существует, но не является enumerable, поэтому `Object.keys()` его не показывает.
