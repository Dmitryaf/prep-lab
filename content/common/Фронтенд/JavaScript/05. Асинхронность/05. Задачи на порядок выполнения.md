# Задачи на порядок выполнения

> [!summary]
> Практикум помогает натренировать главный навык: читать код как последовательность изменений Call Stack, task queues и microtask queue.

## Как решать такие задачи

1. Сначала выпиши весь синхронный код текущей task.
2. Отдельно отмечай callbacks, которые уходят в microtask queue: `.then()`, `.catch()`, `.finally()`, `queueMicrotask()`, продолжение после `await`.
3. Отдельно отмечай будущие tasks: `setTimeout`, DOM events и похожие callbacks.
4. После завершения синхронного кода выполни все microtasks до опустошения очереди.
5. Только потом переходи к следующей task.

## Задача 1. Только синхронный код

```js
console.log('A');

function run() {
  console.log('B');
}

run();

console.log('C');
```

> [!question]- Разбор
> Результат:
>
> ```text
> A
> B
> C
> ```
>
> Сначала выводится `A`, затем вызов `run()` выводит `B`. После возврата из функции выполняется строка с `C`. В этом примере нет отложенных обработчиков: весь код выполняется сразу.

## Задача 2. Promise executor

```js
console.log('A');

new Promise((resolve) => {
  console.log('B');
  resolve();
});

console.log('C');
```

> [!question]- Разбор
> Результат:
>
> ```text
> A
> B
> C
> ```
>
> Executor в `new Promise()` выполняется синхронно в текущем Call Stack. Так как `.then()` нет, microtask queue не пополняется.

## Задача 3. then и setTimeout

```js
console.log('A');

setTimeout(() => {
  console.log('B');
}, 0);

Promise.resolve().then(() => {
  console.log('C');
});

console.log('D');
```

> [!question]- Разбор
> Результат:
>
> ```text
> A
> D
> C
> B
> ```
>
> Текущая макрозадача скрипта выполняет `A`, планирует макрозадачу таймера, добавляет обработчик `.then()` в очередь микрозадач и выводит `D`. После очистки Call Stack Event Loop выполняет микрозадачу `C`. Обработчик таймера `B` выполняется только в следующей макрозадаче.

## Задача 4. Несколько microtasks

```js
console.log('A');

Promise.resolve().then(() => {
  console.log('B');
});

queueMicrotask(() => {
  console.log('C');
});

Promise.resolve().then(() => {
  console.log('D');
});

console.log('E');
```

> [!question]- Разбор
> Результат:
>
> ```text
> A
> E
> B
> C
> D
> ```
>
> `A` и `E` выполняются синхронно. Три обработчика попадают в очередь микрозадач в порядке добавления: `B`, `C`, `D`. После завершения скрипта Event Loop выполняет очередь микрозадач до опустошения очереди.

## Задача 5. Microtask создаёт microtask

```js
Promise.resolve().then(() => {
  console.log('A');

  queueMicrotask(() => {
    console.log('B');
  });
});

Promise.resolve().then(() => {
  console.log('C');
});
```

> [!question]- Разбор
> Результат:
>
> ```text
> A
> C
> B
> ```
>
> После синхронного кода в очереди микрозадач ждут `A` и `C`. Обработчик `A` добавляет `B` в конец очереди. Поэтому сначала выполняется уже ожидающая `C`, затем `B`.

## Задача 6. Цепочка then

```js
Promise.resolve(1)
  .then((value) => {
    console.log(value);
    return value + 1;
  })
  .then((value) => {
    console.log(value);
  });

console.log('A');
```

> [!question]- Разбор
> Результат:
>
> ```text
> A
> 1
> 2
> ```
>
> Первый `.then()` добавляет microtask. Синхронный код продолжает работу и выводит `A`. Затем выполняется первая microtask, выводит `1` и возвращает `2`. После этого следующий `.then()` получает результат и планируется как новая microtask, которая выводит `2`.

## Задача 7. async / await

```js
async function run() {
  console.log('A');
  await Promise.resolve();
  console.log('B');
}

console.log('C');
run();
console.log('D');
```

> [!question]- Разбор
> Результат:
>
> ```text
> C
> A
> D
> B
> ```
>
> `C` выполняется в текущей script task. Вызов `run()` синхронно выводит `A`. На `await` функция приостанавливается, продолжение `B` попадает в microtask queue. Затем script task выводит `D`, и только после этого microtask продолжает `run()`.

## Задача 8. Несколько async-функций

```js
async function first() {
  console.log('A');
  await null;
  console.log('B');
}

async function second() {
  console.log('C');
  await null;
  console.log('D');
}

first();
second();
console.log('E');
```

> [!question]- Разбор
> Результат:
>
> ```text
> A
> C
> E
> B
> D
> ```
>
> `first()` синхронно выводит `A` и ставит продолжение `B` в microtask queue. `second()` синхронно выводит `C` и ставит продолжение `D` следом. Затем текущая task выводит `E`. Microtask queue выполняется по порядку: `B`, затем `D`.

## Задача 9. Promise.all

```js
const firstPromise = Promise.resolve('A');

const secondPromise = new Promise((resolve) => {
  setTimeout(() => {
    resolve('B');
  }, 0);
});

Promise.all([firstPromise, secondPromise]).then((result) => {
  console.log(result);
});

console.log('C');
```

> [!question]- Разбор
> Результат:
>
> ```text
> C
> ['A', 'B']
> ```
>
> В текущей макрозадаче скрипта создаётся успешно выполненный `firstPromise`, создаётся `secondPromise` с будущей макрозадачей таймера, затем подписка `Promise.all(...).then(...)`. Синхронно выводится `C`. Пока `secondPromise` ожидает завершения, итоговый Promise от `Promise.all()` тоже ожидает завершения. В следующей макрозадаче таймера `secondPromise` успешно завершается, после этой макрозадачи очередь микрозадач выполняет обработчик итогового `.then()` и выводит массив в порядке входных Promise.

## Задача 10. Комбинированная

```js
console.log('A');

setTimeout(() => {
  console.log('B');

  Promise.resolve().then(() => {
    console.log('C');
  });
}, 0);

Promise.resolve()
  .then(() => {
    console.log('D');
    return Promise.resolve();
  })
  .then(() => {
    console.log('E');
  });

queueMicrotask(() => {
  console.log('F');
});

console.log('G');
```

> [!question]- Разбор
> Результат:
>
> ```text
> A
> G
> D
> F
> E
> B
> C
> ```
>
> Синхронный код выводит `A`, планирует таймер `B`, добавляет в очередь микрозадачи `D` и `F`, затем выводит `G`.
>
> В очереди микрозадач сначала ждут `D` и `F`. Обработчик `D` выводит свою букву и возвращает уже успешно выполненный Promise. Следующий `.then()` добавится в очередь после обработки этого результата, поэтому `F` выполнится раньше `E`.
>
> После опустошения очереди микрозадач Event Loop выполняет макрозадачу таймера: выводит `B` и добавляет микрозадачу `C`. После завершения макрозадачи таймера выполняются накопившиеся микрозадачи и выводится `C`.
