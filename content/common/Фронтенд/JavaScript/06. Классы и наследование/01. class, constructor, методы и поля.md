# class, constructor, методы и поля

> [!summary]
> `class` - удобный синтаксис для создания объектов через `new`. Методы класса попадают в прототип, а поля создаются на каждом экземпляре.

## Базовый пример

```js
class User {
  constructor(name) {
    this.name = name;
  }

  sayHi() {
    return `Hi, ${this.name}`;
  }
}

const user = new User('Alex');
console.log(user.sayHi());
```

Результат:

```text
Hi, Alex
```

`constructor` вызывается при `new User(...)` и обычно инициализирует свойства экземпляра.

## Где лежат методы

```js
const first = new User('Alex');
const second = new User('Mira');

console.log(first.sayHi === second.sayHi);
console.log(Object.hasOwn(first, 'sayHi'));
```

Результат:

```text
true
false
```

Метод `sayHi` лежит в `User.prototype`, а не копируется в каждый объект.

## Поля класса

```js
class Counter {
  value = 0;

  increment() {
    this.value += 1;
  }
}
```

Поле `value` создается на экземпляре. Метод `increment` находится в прототипе.

## Потеря контекста метода

Методы класса не привязываются к экземпляру автоматически.

```js
class User {
  constructor(name) {
    this.name = name;
  }

  sayHi() {
    console.log(this.name);
  }
}

const user = new User('Alex');
const sayHi = user.sayHi;

sayHi(); // TypeError в strict mode
```

Классы работают в strict mode, поэтому самостоятельный вызов метода теряет `this`.

Подробнее: [[Фронтенд/JavaScript/03. Контекст this/02. Потеря контекста|Потеря контекста]].

## Класс и функция-конструктор

Класс задаёт синтаксис для создания объектов и наследования через прототипы.

```js
console.log(Object.getPrototypeOf(user) === User.prototype);
```

Результат:

```text
true
```

## Частые ошибки

- Говорить, что классы полностью заменяют прототипы.
- Думать, что методы класса автоматически привязаны к экземпляру.
- Ожидать, что метод класса будет собственным свойством экземпляра.
- Забывать `new` при создании экземпляра.

## Как ответить на собеседовании за одну минуту

`class` - синтаксис для объявления конструктора и методов. `constructor` вызывается при `new` и инициализирует экземпляр. Методы, объявленные в теле класса, находятся в прототипе, а поля класса создаются на экземпляре. Классы связаны с прототипной моделью: экземпляр получает прототип `ClassName.prototype`. Метод не запоминает экземпляр автоматически. Если передать его как обработчик и вызвать отдельно от объекта, `this` может потеряться.
