# extends, super и переопределение методов

> [!summary]
> `extends` создает наследование между классами, а `super` позволяет вызвать constructor или метод родителя.

## Базовый пример

```js
class Animal {
  constructor(name) {
    this.name = name;
  }

  speak() {
    return `${this.name} makes a sound`;
  }
}

class Dog extends Animal {
  speak() {
    return `${this.name} barks`;
  }
}

const dog = new Dog('Rex');
console.log(dog.speak());
```

Результат:

```text
Rex barks
```

Метод `Dog.prototype.speak` переопределяет метод из `Animal.prototype`.

## `super()` в constructor

```js
class Dog extends Animal {
  constructor(name, breed) {
    super(name);
    this.breed = breed;
  }
}
```

В constructor дочернего класса нужно вызвать `super()` до обращения к `this`.

## `super.method()`

```js
class Dog extends Animal {
  speak() {
    return `${super.speak()} and then barks`;
  }
}
```

`super.speak()` вызывает метод родителя с текущим `this`.

## Связь с прототипами

Упрощенно:

```text
dog -> Dog.prototype -> Animal.prototype -> Object.prototype -> null
```

Классовое наследование остается прототипным поиском свойств.

## Частые ошибки

- Забывать `super()` в constructor дочернего класса.
- Думать, что `super.method()` вызывает метод на отдельном родительском объекте.
- Путать наследование классов с копированием методов.
- Делать слишком глубокие иерархии там, где проще композиция.

## Как ответить на собеседовании за одну минуту

`extends` связывает дочерний класс с родительским. Экземпляр дочернего класса ищет методы сначала в прототипе дочернего класса, затем в прототипе родителя. В constructor дочернего класса `super()` вызывает constructor родителя и должен быть выполнен до использования `this`. Метод можно переопределить, а через `super.method()` вызвать родительскую реализацию.
