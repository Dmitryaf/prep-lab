# Задачи на классы и наследование

## 1. Метод в прототипе

```js
class User {
  sayHi() {
    return 'hi';
  }
}

const first = new User();
const second = new User();

console.log(first.sayHi === second.sayHi);
console.log(Object.hasOwn(first, 'sayHi'));
```

> [!question]- Разбор
> Вывод:
>
> ```text
> true
> false
> ```
>
> Метод класса находится в `User.prototype`, поэтому экземпляры используют одну функцию.

## 2. Поле класса

```js
class Counter {
  value = 0;
}

const counter = new Counter();

console.log(Object.hasOwn(counter, 'value'));
```

> [!question]- Разбор
> Вывод:
>
> ```text
> true
> ```
>
> Поле класса создается на экземпляре.

## 3. Потеря контекста

```js
class User {
  constructor(name) {
    this.name = name;
  }

  getName() {
    return this.name;
  }
}

const user = new User('Alex');
const getName = user.getName;

console.log(getName());
```

> [!question]- Разбор
> В strict mode будет `TypeError`: метод вызван как обычная функция, объект слева от точки потерян, `this === undefined`.

## 4. `super()`

```js
class Animal {
  constructor(name) {
    this.name = name;
  }
}

class Dog extends Animal {
  constructor(name) {
    this.kind = 'dog';
    super(name);
  }
}

new Dog('Rex');
```

> [!question]- Разбор
> Будет ошибка: в constructor дочернего класса нельзя обращаться к `this` до вызова `super()`.

## 5. Static

```js
class User {
  static create() {
    return new User();
  }
}

const user = new User();

console.log(typeof User.create);
console.log(typeof user.create);
```

> [!question]- Разбор
> Вывод:
>
> ```text
> function
> undefined
> ```
>
> Static-метод находится на классе, а не на экземпляре.
