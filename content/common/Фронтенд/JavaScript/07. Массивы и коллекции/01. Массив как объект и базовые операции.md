# Массив как объект и базовые операции

> [!summary]
> Массив в JavaScript - объект для упорядоченного набора элементов. У него есть числовые индексы и специальное свойство `length`.

## Создание массива

```js
const numbers = [1, 2, 3];
const empty = [];
```

Проверка массива:

```js
console.log(typeof []);
console.log(Array.isArray([]));
```

Результат:

```text
object
true
```

## Индексы и `length`

```js
const items = ['a', 'b'];

console.log(items[0]);
console.log(items.length);

items[2] = 'c';
console.log(items.length);
```

Результат:

```text
a
2
3
```

`length` обычно равен индексу последнего элемента плюс один.

## Изменение массива

```js
const items = ['a'];

items.push('b');
items[0] = 'A';

console.log(items);
```

Результат:

```text
['A', 'b']
```

`const` запрещает переназначить переменную `items`, но не запрещает менять сам массив.

## Разреженные массивы

```js
const items = [];
items[3] = 'x';

console.log(items.length);
console.log(items[0]);
```

Результат:

```text
4
undefined
```

Лучше не создавать holes без необходимости: они усложняют перебор и чтение кода.

## Частые ошибки

- Проверять массив через `typeof`.
- Думать, что `const arr = []` делает массив неизменяемым.
- Забывать, что изменение `length` может удалить элементы.
- Создавать holes присваиванием далеко за текущий конец массива.

## Как ответить на собеседовании за одну минуту

Массив - это объект для упорядоченных данных с индексами и `length`. `typeof []` возвращает `'object'`, поэтому массивы проверяют через `Array.isArray()`. Методы и присваивания могут менять массив на месте, даже если переменная объявлена через `const`. `length` связан с индексами и может изменяться при добавлении или удалении элементов.
