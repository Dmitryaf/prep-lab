# Методы массивов и перебор

> [!summary]
> На собеседованиях важнее уверенно выбирать несколько базовых методов, чем перечислить весь API массивов.

## Мутирующие и немутирующие методы

| Метод | Мутирует массив | Что делает |
| --- | --- | --- |
| `push`, `pop` | да | добавляет/удаляет конец |
| `shift`, `unshift` | да | удаляет/добавляет начало |
| `splice` | да | удаляет/вставляет по индексу |
| `sort`, `reverse` | да | меняет порядок |
| `slice` | нет | возвращает часть массива |
| `concat` | нет | объединяет массивы |
| `map`, `filter` | нет | возвращают новый массив |

## `map`, `filter`, `reduce`

```js
const numbers = [1, 2, 3, 4];

console.log(numbers.map((value) => value * 2));
console.log(numbers.filter((value) => value % 2 === 0));
console.log(numbers.reduce((sum, value) => sum + value, 0));
```

Результат:

```text
[2, 4, 6, 8]
[2, 4]
10
```

- `map` - преобразовать каждый элемент;
- `filter` - оставить часть элементов;
- `reduce` - собрать одно значение.

## `find`, `some`, `every`

```js
const users = [
  { id: 1, active: false },
  { id: 2, active: true },
];

console.log(users.find((user) => user.active));
console.log(users.some((user) => user.active));
console.log(users.every((user) => user.active));
```

`find` возвращает элемент или `undefined`, `some` и `every` возвращают boolean.

## `slice`, `splice`, `concat`, spread

```js
const items = ['a', 'b', 'c'];

console.log(items.slice(1));
console.log(items);
```

`slice` не мутирует.

```js
const items = ['a', 'b', 'c'];
items.splice(1, 1, 'B');

console.log(items);
```

`splice` мутирует.

```js
const merged = [...[1, 2], ...[3]];
const alsoMerged = [1, 2].concat([3]);
```

## Сортировка

`sort()` мутирует массив и по умолчанию сортирует элементы как строки.

```js
const numbers = [10, 2, 1];

numbers.sort();
console.log(numbers);
```

Результат:

```text
[1, 10, 2]
```

Чтобы сортировать числа по возрастанию, передай функцию сравнения:

```js
numbers.sort((a, b) => a - b);
```

## Частые ошибки

- Ждать, что `sort()` не изменит исходный массив.
- Использовать `map` для побочных эффектов вместо `forEach` или `for...of`.
- Писать сложный `reduce`, который хуже читается, чем цикл.
- Забывать начальное значение `reduce`.

## Как ответить на собеседовании за одну минуту

Массивы имеют мутирующие и немутирующие методы. Для преобразования используют `map`, для отбора `filter`, для сворачивания в одно значение `reduce`, для поиска первого элемента `find`. `some` проверяет, есть ли хотя бы один подходящий элемент, `every` - подходят ли все. `slice` возвращает копию части массива, `splice` меняет массив. `sort()` меняет исходный массив; для числового порядка ему передают функцию сравнения.
