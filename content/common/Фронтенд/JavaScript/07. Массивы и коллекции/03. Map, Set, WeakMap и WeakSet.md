# Map, Set, WeakMap и WeakSet

> [!summary]
> `Map` хранит пары ключ-значение, `Set` хранит уникальные значения, а weak-коллекции позволяют связывать данные с объектами без удержания сильной ссылки.

## `Set`

```js
const ids = new Set([1, 2, 2, 3]);

console.log([...ids]);
console.log(ids.has(2));
```

Результат:

```text
[1, 2, 3]
true
```

`Set` удобен для уникальных значений.

## `Map`

```js
const cache = new Map();
const key = { id: 1 };

cache.set(key, 'result');

console.log(cache.get(key));
console.log(cache.has(key));
```

`Map` позволяет использовать ключи любого типа, включая объекты.

## Object или Map

| Сценарий | Что выбрать |
| --- | --- |
| JSON, DTO, фиксированная структура | `Object` |
| ключи только строки/symbol и простые данные | `Object` |
| ключи любого типа | `Map` |
| частое добавление/удаление | часто удобнее `Map` |
| уникальные значения | `Set` |

Не стоит обещать, что `Map` всегда быстрее объекта. Производительность зависит от движка и сценария.

## WeakMap и WeakSet

`WeakMap` хранит ключи-объекты слабо. Если объект больше нигде не достижим, запись не должна удерживать его в памяти.

```js
const metadata = new WeakMap();
const element = {};

metadata.set(element, { selected: true });
console.log(metadata.get(element));
```

Ограничения:

- обычно ключи `WeakMap` и значения `WeakSet` — объекты;
- нельзя итерировать;
- нет `size`.

> [!note]- Углубление: символы в слабых коллекциях
> Современный ECMAScript также допускает незарегистрированные символы, например `Symbol('key')`. `Symbol.for('key')` не подходит: такой символ хранится в глобальном реестре. Для базовой практики достаточно примера с объектами.

Подробнее про слабые ссылки: [[Фронтенд/JavaScript/10. Память и сборка мусора/02. Достижимость и garbage collection|Достижимость и garbage collection]].

## Частые ошибки

- Использовать объект как ключ в обычном object literal и ожидать уникальный ключ объекта.
- Говорить, что `Map` не имеет прототипа. У `Map` есть свой прототип; смысл в том, что пользовательские ключи не конфликтуют с `toString` как свойствами объекта-словаря.
- Пытаться перебрать `WeakMap`.
- Выбирать `Map` только из-за мифа "он всегда быстрее".

## Как ответить на собеседовании за одну минуту

`Set` хранит уникальные значения. `Map` хранит пары ключ-значение и позволяет ключи любого типа, поэтому удобен для кэшей, динамических словарей и связей с объектами. Обычный объект лучше подходит для JSON и фиксированной структуры данных. `WeakMap` и `WeakSet` обычно используют с объектами; эти коллекции не перебираются; их используют, когда данные не должны удерживать объект от сборки мусора.
