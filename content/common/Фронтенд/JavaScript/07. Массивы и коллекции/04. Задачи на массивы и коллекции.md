# Задачи на массивы и коллекции

## 1. Проверка массива

```js
console.log(typeof []);
console.log(Array.isArray([]));
```

> [!question]- Разбор
> Вывод:
>
> ```text
> object
> true
> ```
>
> Массив - объект, но проверяется через `Array.isArray()`.

## 2. `push` и ссылка

```js
const a = [1];
const b = a;

b.push(2);

console.log(a);
```

> [!question]- Разбор
> Вывод:
>
> ```text
> [1, 2]
> ```
>
> `a` и `b` ссылаются на один массив. `push` мутирует его.

## 3. `map`

```js
const numbers = [1, 2, 3];
const result = numbers.map((value) => value * 2);

console.log(numbers);
console.log(result);
```

> [!question]- Разбор
> `map` не меняет исходный массив, а возвращает новый:
>
> ```text
> [1, 2, 3]
> [2, 4, 6]
> ```

## 4. `splice`

```js
const items = ['a', 'b', 'c'];
const removed = items.splice(1, 1);

console.log(items);
console.log(removed);
```

> [!question]- Разбор
> Вывод:
>
> ```text
> ['a', 'c']
> ['b']
> ```
>
> `splice` мутирует массив и возвращает удаленные элементы.

## 5. `sort`

```js
const numbers = [10, 2, 1];
numbers.sort();

console.log(numbers);
```

> [!question]- Разбор
> Вывод:
>
> ```text
> [1, 10, 2]
> ```
>
> По умолчанию `sort` сортирует как строки. Для чисел нужен `(a, b) => a - b`.

## 6. Уникальные значения

```js
const values = [1, 2, 2, 3];
const unique = [...new Set(values)];

console.log(unique);
```

> [!question]- Разбор
> `Set` хранит уникальные значения:
>
> ```text
> [1, 2, 3]
> ```

## 7. Map с объектным ключом

```js
const map = new Map();
const key = { id: 1 };

map.set(key, 'value');

console.log(map.get({ id: 1 }));
console.log(map.get(key));
```

> [!question]- Разбор
> Вывод:
>
> ```text
> undefined
> value
> ```
>
> Объектные ключи сравниваются по ссылке. Новый `{ id: 1 }` - другой ключ.
