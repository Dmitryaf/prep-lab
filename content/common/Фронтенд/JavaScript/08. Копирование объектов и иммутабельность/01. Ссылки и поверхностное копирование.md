# Ссылки и поверхностное копирование

> [!summary]
> Присваивание объекта копирует ссылку. Spread и `Object.assign()` создают новый объект только на верхнем уровне.

## Присваивание ссылки

```js
const user = { name: 'Alex' };
const copy = user;

copy.name = 'Mira';

console.log(user.name);
```

Результат:

```text
Mira
```

`copy` и `user` указывают на один объект.

## Spread

```js
const user = { name: 'Alex', age: 30 };
const copy = { ...user };

console.log(copy === user);
console.log(copy.name);
```

Результат:

```text
false
Alex
```

Spread создал новый объект и скопировал собственные enumerable-свойства.

## `Object.assign()`

```js
const copy = Object.assign({}, user);
```

Для обычного поверхностного копирования объекта разворот свойств через spread обычно читается проще.

## Вложенные объекты

```js
const state = {
  user: {
    name: 'Alex',
  },
};

const nextState = { ...state };
nextState.user.name = 'Mira';

console.log(state.user.name);
```

Результат:

```text
Mira
```

Скопирован только верхний объект. `state.user` и `nextState.user` все еще указывают на один вложенный объект.

## Частые ошибки

- Думать, что `const copy = obj` создает копию.
- Называть spread глубоким копированием.
- Мутировать вложенный объект после shallow copy.
- Забывать, что массивы тоже копируются поверхностно через `[...items]`.

## Как ответить на собеседовании за одну минуту

Объекты присваиваются по ссылке: новая переменная указывает на тот же объект. Spread и `Object.assign()` создают новый объект, но это поверхностная копия: вложенные объекты остаются теми же ссылками. Поэтому для обновления вложенных данных нужно копировать каждый уровень на пути изменения или использовать подходящий deep clone, если действительно нужна полная копия.
