# Задачи на копирование и иммутабельность

## 1. Присваивание ссылки

```js
const user = { name: 'Alex' };
const copy = user;

copy.name = 'Mira';

console.log(user.name);
```

> [!question]- Разбор
> Вывод:
>
> ```text
> Mira
> ```
>
> `copy` и `user` указывают на один объект.

## 2. Shallow copy

```js
const user = { name: 'Alex' };
const copy = { ...user };

copy.name = 'Mira';

console.log(user.name);
console.log(copy.name);
```

> [!question]- Разбор
> Вывод:
>
> ```text
> Alex
> Mira
> ```
>
> Верхний объект скопирован, поэтому изменение простого свойства копии не меняет оригинал.

## 3. Вложенный объект

```js
const state = {
  user: {
    name: 'Alex',
  },
};

const copy = { ...state };
copy.user.name = 'Mira';

console.log(state.user.name);
```

> [!question]- Разбор
> Вывод:
>
> ```text
> Mira
> ```
>
> Spread скопировал только верхний уровень. Вложенный `user` общий.

## 4. Иммутабельное обновление

```js
const state = {
  user: {
    name: 'Alex',
    age: 30,
  },
};

const nextState = {
  ...state,
  user: {
    ...state.user,
    age: 31,
  },
};

console.log(state.user.age);
console.log(nextState.user.age);
```

> [!question]- Разбор
> Вывод:
>
> ```text
> 30
> 31
> ```
>
> Скопирован верхний объект и вложенный `user`. Старое состояние не мутировалось.

## 5. Массив объектов

```js
const items = [
  { id: 1, done: false },
  { id: 2, done: false },
];

const nextItems = items.map((item) =>
  item.id === 2 ? { ...item, done: true } : item
);

console.log(items[1].done);
console.log(nextItems[1].done);
```

> [!question]- Разбор
> Вывод:
>
> ```text
> false
> true
> ```
>
> Для измененного элемента создан новый объект. Остальные элементы можно оставить прежними ссылками.

## 6. JSON-copy

```js
const value = {
  date: new Date('2026-01-01'),
  missing: undefined,
};

const copy = JSON.parse(JSON.stringify(value));

console.log(typeof copy.date);
console.log('missing' in copy);
```

> [!question]- Разбор
> Вывод:
>
> ```text
> string
> false
> ```
>
> `Date` сериализуется в строку, свойство с `undefined` теряется.
