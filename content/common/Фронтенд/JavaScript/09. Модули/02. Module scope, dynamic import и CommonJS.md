# Module scope, dynamic import и CommonJS

> [!summary]
> ES Module отличается от classic script собственной областью видимости, strict mode и статическими импортами. Dynamic `import()` нужен, когда модуль загружается по условию.

## Module scope

Переменные верхнего уровня в ES Module не становятся глобальными переменными.

```js
// module.js
const value = 1;
```

`value` доступен внутри модуля, но не появляется как свойство `window`.

## Strict mode

ES Modules выполняются в strict mode автоматически. Отдельная строка `'use strict';` не нужна.

## Статический импорт

```js
import { sum } from './math.js';
```

Статический импорт должен быть на верхнем уровне модуля. Такая структура помогает заранее построить граф зависимостей.

## Dynamic import

```js
async function loadFeature() {
  const module = await import('./feature.js');
  module.run();
}
```

`import()` возвращает Promise и может использоваться по условию. Это основа lazy loading.

## Tree shaking

Tree shaking — удаление неиспользуемого кода при сборке. Сборщик анализирует импорты и экспорты и решает, что можно убрать. Статическая структура ESM помогает этому анализу; само наличие ESM ещё не означает, что любой неиспользуемый фрагмент будет удалён.

## CommonJS кратко

CommonJS использует `require()` и `module.exports`.

```js
const fs = require('node:fs');

module.exports = {
  readConfig,
};
```

Главное практическое отличие: ESM строится вокруг статического `import/export`, а CommonJS исторически вокруг синхронного `require()` во время выполнения.

## Частые ошибки

- Думать, что top-level переменная модуля попадает в `window`.
- Пытаться использовать статический `import` внутри `if`.
- Ожидать, что tree shaking сработает при любой форме динамического кода.
- Смешивать ESM и CommonJS без понимания настроек среды выполнения и сборщика.

## Как ответить на собеседовании за одну минуту

ES Module имеет собственную область видимости и автоматически strict mode. Статический `import` находится на верхнем уровне и позволяет анализировать граф зависимостей заранее. Dynamic `import()` возвращает Promise и используется для условной или ленивой загрузки. CommonJS использует `require()` и `module.exports`; в современном frontend основной формат - ESM.

> [!note]- Углубление: live bindings
> Импорт сохраняет связь с переменной исходного модуля. Например, модуль экспортирует `let count = 0`, а его функция увеличивает `count`. После вызова этой функции другой модуль прочитает через импорт уже новое значение. Такая связь называется live binding.
