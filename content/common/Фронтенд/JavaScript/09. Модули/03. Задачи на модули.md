# Задачи на модули

## 1. Named import

```js
// math.js
export const sum = (a, b) => a + b;

// app.js
import sum from './math.js';
```

> [!question]- Разбор
> Ошибка в форме импорта. `sum` экспортирован как named export, значит импортировать нужно так:
>
> ```js
> import { sum } from './math.js';
> ```

## 2. Default import

```js
// logger.js
export default function log(message) {
  console.log(message);
}

// app.js
import { log } from './logger.js';
```

> [!question]- Разбор
> `log` экспортирован как default export. Импорт должен быть без фигурных скобок:
>
> ```js
> import log from './logger.js';
> ```

## 3. Module scope

```js
// config.js
const apiUrl = '/api';
```

Будет ли `window.apiUrl` доступен в браузере?

> [!question]- Разбор
> Нет, если файл выполняется как ES Module. Привязка имени на верхнем уровне модуля находится в его собственной области видимости и не становится свойством глобального объекта.

## 4. Dynamic import

```js
async function openAdmin() {
  const admin = await import('./admin.js');
  admin.open();
}
```

> [!question]- Разбор
> `import()` загружает модуль динамически и возвращает Promise. Это удобно для lazy loading кода, который нужен не сразу.
