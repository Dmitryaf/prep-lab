# Задачи на память и утечки

## 1. Ссылка на объект

```js
let first = { name: 'Alex' };
let second = first;

first = null;

console.log(second.name);
```

> [!question]- Разбор
> Вывод:
>
> ```text
> Alex
> ```
>
> Объект все еще достижим через `second`, поэтому он не мусор.

## 2. Замыкание

```js
function createLogger() {
  const largeData = new Array(1000000).fill('x');

  return function log() {
    console.log(largeData.length);
  };
}

const logger = createLogger();
```

> [!question]- Разбор
> `logger` удерживает доступ к `largeData`. Пока `logger` достижим, данные тоже остаются достижимыми.

## 3. Очистка таймеров

**ID вопроса:** 3. Timer cleanup

```js
function start() {
  const timerId = setInterval(() => {
    console.log('tick');
  }, 1000);

  return () => clearInterval(timerId);
}
```

> [!question]- Разбор
> Функция возвращает функцию очистки ресурсов. Без `clearInterval` таймер продолжал бы жить и удерживать обработчик.
