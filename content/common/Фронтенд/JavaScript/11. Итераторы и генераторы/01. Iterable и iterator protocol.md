# Iterable и iterator protocol

> [!summary]
> Iterable - объект, который можно перебирать. Он предоставляет метод `Symbol.iterator`, возвращающий iterator с методом `next()`.

## Где используются iterable

`for...of`, spread в массиве и аргументах, а также деструктуризация массива работают с итерируемыми значениями. Объектный spread `{ ...value }` и объектная деструктуризация используют свойства и не требуют `Symbol.iterator`.

```js
const values = [1, 2, 3];

for (const value of values) {
  console.log(value);
}

console.log([...values]);
const [first] = values;
```

Встроенные iterable: массивы, строки, `Map`, `Set`, многие DOM-коллекции.

## Iterator

Итератор запоминает, на каком месте остановился перебор. Каждый вызов `next()` возвращает следующее значение в поле `value`. Поле `done: true` сообщает, что перебор закончен.

```js
const iterator = [1, 2][Symbol.iterator]();

console.log(iterator.next());
console.log(iterator.next());
console.log(iterator.next());
```

Результат:

```text
{ value: 1, done: false }
{ value: 2, done: false }
{ value: undefined, done: true }
```

## Собственный iterable

```js
const range = {
  from: 1,
  to: 3,

  [Symbol.iterator]() {
    let current = this.from;
    const last = this.to;

    return {
      next() {
        if (current <= last) {
          return { value: current++, done: false };
        }

        return { value: undefined, done: true };
      },
    };
  },
};

console.log([...range]);
```

Результат:

```text
[1, 2, 3]
```

## Частые ошибки

- Путать iterable и iterator.
- Возвращать из `Symbol.iterator` объект без `next()`.
- Ожидать, что обычный объект можно сразу перебрать через `for...of`.

## Как ответить на собеседовании за одну минуту

Iterable - объект, у которого есть метод `Symbol.iterator`. Этот метод возвращает iterator. Iterator имеет `next()`, который возвращает объект `{ value, done }`. `for...of`, spread в массиве/аргументах и деструктуризация массива используют этот протокол. Массивы, строки, `Map` и `Set` уже iterable.

> [!note]- Углубление: terminology
> В спецификации отдельно описываются итерируемые значения, объекты итераторов и объекты результатов итерации. Для первого чтения достаточно модели `Symbol.iterator -> iterator -> next() -> { value, done }`.
