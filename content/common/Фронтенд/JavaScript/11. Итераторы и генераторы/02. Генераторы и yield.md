# Генераторы и yield

> [!summary]
> Generator function объявляется через `function*` и возвращает generator object, который является iterator. `yield` выдает очередное значение и приостанавливает выполнение.

## Базовый пример

```js
function* createNumbers() {
  yield 1;
  yield 2;
  yield 3;
}

console.log([...createNumbers()]);
```

Результат:

```text
[1, 2, 3]
```

## Ленивые вычисления

Генератор не вычисляет все значения сразу.

```js
function* ids() {
  let id = 1;

  while (true) {
    yield id;
    id += 1;
  }
}

const iterator = ids();

console.log(iterator.next().value);
console.log(iterator.next().value);
```

Результат:

```text
1
2
```

## Практические сценарии

- последовательная выдача данных;
- lazy ranges;
- обход дерева;
- генерация id;
- адаптер под `for...of`.

## Частые ошибки

- Ожидать, что body генератора выполнится сразу при вызове функции.
- Путать `yield` и `return`.
- Использовать генераторы там, где простой массив читается лучше.

## Как ответить на собеседовании за одну минуту

Генератор объявляется через `function*`. При вызове он возвращает iterator, а код внутри начинает выполняться только при `next()`. `yield` возвращает очередное значение и ставит выполнение на паузу. Поэтому генераторы удобны для ленивых последовательностей и собственных iterable-объектов.
