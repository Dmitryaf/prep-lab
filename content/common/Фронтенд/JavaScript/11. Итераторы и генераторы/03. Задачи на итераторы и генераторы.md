# Задачи на итераторы и генераторы

## 1. Iterator вручную

```js
const iterator = ['a', 'b'][Symbol.iterator]();

console.log(iterator.next());
console.log(iterator.next());
console.log(iterator.next());
```

> [!question]- Разбор
> Вывод:
>
> ```text
> { value: 'a', done: false }
> { value: 'b', done: false }
> { value: undefined, done: true }
> ```

## 2. Object literal и for...of

```js
const obj = { a: 1, b: 2 };

for (const value of obj) {
  console.log(value);
}
```

> [!question]- Разбор
> Будет `TypeError`: обычный object literal не iterable. Для объектов обычно используют `Object.keys()`, `Object.values()` или `Object.entries()`.

## 3. Generator

```js
function* gen() {
  console.log('A');
  yield 1;
  console.log('B');
  yield 2;
}

const iterator = gen();
console.log('start');
console.log(iterator.next().value);
console.log(iterator.next().value);
```

> [!question]- Разбор
> Вывод:
>
> ```text
> start
> A
> 1
> B
> 2
> ```
>
> Тело генератора не выполняется при `gen()`. Оно выполняется шагами при `next()`.
