# Proxy traps и Reflect

> [!summary]
> `Proxy` позволяет перехватывать операции над объектом. `Reflect` помогает выполнить стандартное поведение внутри trap.

## Базовый пример

```js
const user = { name: 'Alex' };

const proxy = new Proxy(user, {
  get(target, property, receiver) {
    console.log(`read ${String(property)}`);
    return Reflect.get(target, property, receiver);
  },
});

console.log(proxy.name);
```

Результат:

```text
read name
Alex
```

## Популярные traps

| Trap | Операция |
| --- | --- |
| `get` | чтение свойства |
| `set` | запись свойства |
| `has` | оператор `in` |
| `deleteProperty` | `delete obj.key` |
| `ownKeys` | получение списка ключей |

## `Reflect`

```js
const proxy = new Proxy({}, {
  set(target, property, value, receiver) {
    if (typeof value === 'undefined') {
      throw new Error('undefined is not allowed');
    }

    return Reflect.set(target, property, value, receiver);
  },
});
```

`Reflect.set()` возвращает boolean, что удобно для корректного поведения `set` trap.

## Где используют

- валидация записи;
- логирование доступа;
- reactive-системы;
- lazy objects;
- защита API в dev-mode.

## Ограничения

- Proxy усложняет отладку;
- не все объекты можно прозрачно проксировать;
- производительность может быть хуже обычного объекта;
- нужно соблюдать неизменяемые ограничения языка.

## Как ответить на собеседовании за одну минуту

`Proxy` создает обертку над объектом и позволяет перехватывать операции через traps. Например, `get` перехватывает чтение, `set` - запись, `has` - оператор `in`. `Reflect` дает методы для выполнения стандартного поведения, поэтому внутри trap часто вызывают соответствующий `Reflect.get` или `Reflect.set`.

> [!note]- Углубление: invariants
> Спецификация задаёт ограничения для обработчиков Proxy: они не могут произвольно нарушать свойства исходного объекта. Например, нельзя скрыть некоторые свойства, запрещённые к перенастройке. Обработчики должны согласовываться с реальным состоянием target — объекта, который оборачивает Proxy. Эти ограничения называют инвариантами.
