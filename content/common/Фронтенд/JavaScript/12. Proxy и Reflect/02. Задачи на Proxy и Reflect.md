# Задачи на Proxy и Reflect

## 1. Логирование чтения

```js
const target = { name: 'Alex' };
const proxy = new Proxy(target, {
  get(target, property, receiver) {
    console.log(property);
    return Reflect.get(target, property, receiver);
  },
});

console.log(proxy.name);
```

> [!question]- Разбор
> Сначала trap `get` выводит имя свойства, затем возвращает значение:
>
> ```text
> name
> Alex
> ```

## 2. Проверка записи

```js
const user = new Proxy({}, {
  set(target, property, value, receiver) {
    if (property === 'age' && value < 0) {
      return false;
    }

    return Reflect.set(target, property, value, receiver);
  },
});

user.age = 20;
console.log(user.age);
```

> [!question]- Разбор
> Запись проходит через `set` trap. Для `20` условие не блокирует запись, поэтому `Reflect.set()` сохраняет значение.
