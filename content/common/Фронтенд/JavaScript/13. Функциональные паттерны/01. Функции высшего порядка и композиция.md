# Функции высшего порядка и композиция

> [!summary]
> Функция высшего порядка принимает функцию как аргумент или возвращает функцию. Композиция соединяет несколько функций в цепочку обработки.

## Функция высшего порядка

```js
function withLogging(fn) {
  return function logged(...args) {
    console.log('call');
    return fn.apply(this, args);
  };
}
```

`map`, `filter`, `reduce` тоже используют функции как аргументы.

## Композиция

```js
const compose = (first, second) => (value) => first(second(value));

const double = (value) => value * 2;
const square = (value) => value ** 2;

const squareDouble = compose(square, double);

console.log(squareDouble(3));
```

Результат:

```text
36
```

## Pipe: читать преобразование слева направо

У `compose(square, double)(3)` сначала получается 6, затем 36: функции читаются справа налево. `pipe(double, square)(3)` описывает те же действия слева направо. Выбирай запись, которую легче читать в конкретном коде.

Самостоятельная реализация с пустой цепочкой: [[Собеседования/Практика/JavaScript#Pipe: результат одной функции передать следующей|задача pipe]].

## Когда полезно

- декомпозиция преобразований;
- переиспользование маленьких функций;
- обертки вокруг callbacks;
- декларативная обработка массивов.

## Частые ошибки

- Делать композицию ради красоты, когда обычный код читается проще.
- Прятать побочные эффекты в функциях, которые выглядят чистыми.
- Создавать слишком глубокие цепочки без именованных шагов.

## Как ответить на собеседовании за одну минуту

Функция высшего порядка принимает другую функцию или возвращает функцию. Например, `map` получает функцию, которая преобразует каждый элемент массива. При композиции результат одной функции передаётся следующей: сначала удваиваем число, потом возводим его в квадрат. Такая цепочка полезна, когда её шаги проще читать и использовать отдельно.
