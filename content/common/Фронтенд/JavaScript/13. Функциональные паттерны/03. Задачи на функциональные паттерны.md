# Задачи на функциональные паттерны

## 1. once

Реализуй `once(fn)`.

> [!question]- Разбор
> ```js
> function once(fn) {
>   let called = false;
>   let result;
>
>   return function wrapped(...args) {
>     if (!called) {
>       called = true;
>       result = fn.apply(this, args);
>     }
>
>     return result;
>   };
> }
> ```
>
> Замыкание хранит `called` и `result`. `apply` сохраняет `this` и аргументы.

## 2. memoize

Реализуй memoization для функции с одним примитивным аргументом.

> [!question]- Разбор
> ```js
> function memoize(fn) {
>   const cache = new Map();
>
>   return function memoized(value) {
>     if (cache.has(value)) {
>       return cache.get(value);
>     }
>
>     const result = fn(value);
>     cache.set(value, result);
>     return result;
>   };
> }
> ```

## 3. compose

```js
const double = (value) => value * 2;
const square = (value) => value ** 2;

const fn = compose(square, double);
console.log(fn(3));
```

> [!question]- Разбор
> ```js
> const compose = (first, second) => (value) => first(second(value));
> ```
>
> Сначала `double(3)` дает `6`, затем `square(6)` дает `36`.
