# Задачи на функциональные паттерны

## 1. once

Реализуй `once(fn)`: сохрани первый нормально возвращённый результат, передай `this` и аргументы. При синхронном исключении разреши повторную попытку; возвращённый Promise кешируется как обычное значение, даже если позже отклонится.

> [!question]- Разбор
> ```js
> function once(fn) {
>   let called = false;
>   let result;
>
>   return function wrapped(...args) {
>     if (!called) {
>       result = fn.apply(this, args);
>       called = true;
>     }
>
>     return result;
>   };
> }
> ```
>
> Замыкание хранит `called` и `result`. `apply` сохраняет `this` и аргументы.

## 2. memoize

Реализуй memoization для чистой функции с одним примитивным аргументом. Результат не зависит от `this` и внешних изменений. Значения `0`, `false` и `undefined` тоже должны кешироваться.

> [!question]- Разбор
> ```js
> function memoize(fn) {
>   const cache = new Map();
>
>   return function memoized(value) {
>     if (cache.has(value)) {
>       return cache.get(value);
>     }
>
>     const result = fn(value);
>     cache.set(value, result);
>     return result;
>   };
> }
> ```

## 3. compose

```js
const double = (value) => value * 2;
const square = (value) => value ** 2;

const fn = compose(square, double);
console.log(fn(3));
```

> [!question]- Разбор
> ```js
> const compose = (first, second) => (value) => first(second(value));
> ```
>
> Сначала `double(3)` дает `6`, затем `square(6)` дает `36`.
