# React

Последовательный маршрут от компонентов до запросов, тестов и серверного рендеринга. Можно изучать независимо от Vue; короткие сравнения помогают заметить различия, если Vue уже знаком. Общие JavaScript, TypeScript, HTTP и браузерные механизмы остаются в своих разделах.

## Применение

Возьми один сценарий: список документов → выбор → редактор → сохранение → ошибка и повтор. Найди владельца каждого значения, предскажи следующий экран и проверь переход. Начать можно с учебного стенда из последней заметки. Учебные примеры не описывают архитектуру конкретного приложения.

## Быстрое повторение

- JSX, props, callbacks и children: кто владеет данными и кто сообщает о действии.
- Снимок state, updater, иммутабельность и производные значения.
- Render/commit, key, сохранение черновика и StrictMode.
- Эффект как связь с внешней системой, зависимости, очистка ресурсов и замыкания с устаревшими значениями.
- Ref, DOM и custom hooks; независимость вызовов и правила Hooks.
- Формы, reducer/Context, URL и серверный кэш.
- Отмена и актуальность запросов; старые success/catch/finally.
- Профилирование, мемоизация, transitions; Error Boundary, Suspense и гидратация.

Для устного повторения: [[Собеседования/Темы/React|30 вопросов]]. Для самостоятельного решения: [[Собеседования/Практика/React|задачи с закрытыми разборами]]. Запускаемый пример: [[Фронтенд/React/14. Тестирование и практикум|практикум]].

## Приоритеты

P0 внутри маршрута — компоненты, state, effects, hooks, формы и владельцы данных. P1 — DOM-интеграции, маршруты, производительность, ошибки, SSR и практикум. P2 — подробности Fiber, сложные обобщённые компонентные API и специализированные интеграции. Это порядок учебной ценности, а не оценка знаний.

Для Senior-подготовки важно объяснить причину ошибки, ограничения решения и проверку. Actions, useOptimistic, useEffectEvent и Compiler разбираются в соответствующих темах с условиями применимости. Next.js, Redux Toolkit, Zustand и TanStack Query углубляются по требованиям роли; они не становятся обязательными зависимостями каждого React-приложения.

## Если знаком Vue

| Знакомая задача | На что обратить внимание в React |
| --- | --- |
| computed и watch | Производное значение часто вычисляется при render; effect нужен для внешней системы |
| emits и slots | Callback props, children и render props описывают контракт компонента |
| Composable | Hook вызывается при render; порядок Hooks и замыкания имеют значение |
| Pinia | Сначала различай локальный state, Context, внешний store и серверный кэш |
| nextTick и жизненный цикл | Не переноси модель очереди Vue на render/commit/effects React |

## Границы и версии

База примеров — функциональные компоненты React 19. Запускаемый стенд фиксирует React 19.3.1 и React Router 7.18.4. Новые возможности нельзя автоматически переносить в старый проект: useEffectEvent требует React 19.2+, синтаксис Context/ref отличается от React 18. Compiler в стенде не включён. Точные зависимости — в его package.json и lockfile.
