## Быстрое повторение

- inference и явные публичные контракты;
- `type` и `interface`;
- union, narrowing, discriminant и `never`;
- `unknown` против `any`;
- generics и constraints;
- `keyof`, indexed access, mapped/conditional и utility types;
- типизация API и проверка полученных данных во время работы программы;
- `strict`, `.d.ts` и постепенная миграция.

Практика проектирования и ревью: [[Собеседования/Практика/Ревью JavaScript и TypeScript|Ревью JavaScript и TypeScript]].

## Приоритеты

- P0: базовые типы, функции, unions, narrowing, generics, API boundaries.
- P1: utility/type operators, overloads, declaration files, migration.
- P2: рекурсивные типы, variance, compiler internals и сложные type-level вычисления.
