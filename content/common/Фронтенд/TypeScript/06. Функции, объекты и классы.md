# Функции, объекты и классы

> [!summary]
> В TypeScript важно описать параметры и результаты публичных функций, форму объектов и доступные методы классов. Как функции, объекты и классы ведут себя во время работы программы, определяет JavaScript.

## Функции

```ts
function createUser(name: string, age?: number): {
  id: string;
  name: string;
  age?: number;
} {
  return {
    id: crypto.randomUUID(),
    name,
    age,
  };
}
```

Для callback лучше описывать сигнатуру отдельно:

```ts
type ChangeHandler<T> = (value: T) => void;

function subscribe<T>(handler: ChangeHandler<T>) {}
```

## Перегрузки функций

**ID вопроса:** Overloads

Перегрузки нужны, когда одна функция имеет несколько публичных вариантов вызова:

```ts
function format(value: string): string;
function format(value: number): string;
function format(value: string | number): string {
  return String(value);
}
```

Если поведение можно понятно описать объединением или параметром типа, перегрузки не нужны.

## Объекты

```ts
type Config = {
  readonly apiUrl: string;
  retryCount?: number;
  headers: Record<string, string>;
};
```

`readonly` защищает от присваивания через этот тип, но не блокирует изменение вложенных объектов во время выполнения.

## Классы

```ts
class UserService {
  constructor(private readonly apiUrl: string) {}

  async loadUser(id: string): Promise<User> {
    const response = await fetch(`${this.apiUrl}/users/${encodeURIComponent(id)}`);
    if (!response.ok) throw new Error(`Ошибка HTTP: ${response.status}`);
    const value: unknown = await response.json();
    if (!isUser(value)) throw new Error('Неверные данные пользователя');
    return value;
  }
}
```

Здесь `User` и `isUser` — тип и проверка из [[Фронтенд/TypeScript/03. Объединения типов и сужение|Объединения типов и сужение]]. Класс не заменяет проверку сетевой границы.

TypeScript добавляет типы полей, параметров, модификаторы доступа и checks, но прототипное поведение и `this` остаются JavaScript-механикой.

## Частые ошибки

- Не типизировать возвращаемый тип публичной async-функции.
- Добавлять перегрузки там, где достаточно объединения типов.
- Считать `private` способом защиты данных во время выполнения программы; для приватности во время выполнения есть JavaScript-поля `#field`.
- Дублировать сложные описания объектов прямо в месте использования вместо именованного типа.
- Путать `readonly` в типах и глубокую неизменяемость объекта.

## Как ответить на собеседовании за одну минуту

Я явно типизирую параметры и типы результатов публичных функций, особенно у асинхронных функций и API-границ. Типы обработчиков описываю отдельными именованными типами функций, объекты описываю через `type` или `interface`, а классы типизирую там, где они дают понятный публичный API. Перегрузки использую только для действительно разных вариантов вызова. Поведение функций, объектов и классов во время выполнения определяет JavaScript.
