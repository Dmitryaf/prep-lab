# Практикум по TypeScript

> [!summary]
> Эти задачи помогают подготовиться к собеседованию на middle-позицию: функции, `any`, сужение типов, данные API, параметры типов, вспомогательные типы и проверка всех вариантов.

## Задача 1. Определить тип функции

Опиши тип `SearchHandler`: принимает query и options, возвращает Promise со списком результатов.

```ts
type SearchResult = {
  id: string;
  title: string;
};
```

> [!question]- Разбор
> ```ts
> type SearchOptions = {
>   limit?: number;
>   signal?: AbortSignal;
> };
>
> type SearchHandler = (
>   query: string,
>   options?: SearchOptions,
> ) => Promise<SearchResult[]>;
> ```

## Задача 2. Исправить `any`

```ts
function readTitle(data: any): string {
  return data.title.toUpperCase();
}
```

> [!question]- Разбор
> ```ts
> function readTitle(data: unknown): string | null {
>   if (
>     typeof data === 'object' &&
>     data !== null &&
>     'title' in data &&
>     typeof data.title === 'string'
>   ) {
>     return data.title.toUpperCase();
>   }
>
>   return null;
> }
> ```

## Задача 3. Сужение объединения типов

**ID вопроса:** Задача 3. Union narrowing

```ts
type Input = string | string[] | null;
```

Верни длину строки, длину массива или `0`.

> [!question]- Разбор
> ```ts
> function getLength(input: Input): number {
>   if (input === null) {
>     return 0;
>   }
>
>   return input.length;
> }
> ```

## Задача 4. Ответ API

**ID вопроса:** Задача 4. API response

Опиши тип ответа: успешный ответ содержит `data`, ошибка содержит `message`.

> [!question]- Разбор
> ```ts
> type ApiResponse<T> =
>   | { ok: true; data: T }
>   | { ok: false; message: string };
> ```

## Задача 5. Вспомогательная функция с параметром типа

**ID вопроса:** Задача 5. Generic helper

Напиши `pluck`.

> [!question]- Разбор
> ```ts
> function pluck<T, K extends keyof T>(items: T[], key: K): T[K][] {
>   return items.map((item) => item[key]);
> }
> ```

## Задача 6. Pick/Omit/Record

Для `User` сделай preview, patch и словарь по id.

```ts
type User = {
  id: string;
  name: string;
  email: string;
  role: 'admin' | 'user';
};
```

> [!question]- Разбор
> ```ts
> type UserPreview = Pick<User, 'id' | 'name'>;
> type UserPatch = Partial<Omit<User, 'id'>>;
> type UsersById = Record<string, User>;
> ```

## Задача 7. Варианты с общим отличительным полем

**ID вопроса:** Задача 7. Discriminated union

Опиши состояние формы: editing, submitting, submitted, failed.

> [!question]- Разбор
> ```ts
> type FormState =
>   | { status: 'editing' }
>   | { status: 'submitting' }
>   | { status: 'submitted'; id: string }
>   | { status: 'failed'; error: string };
> ```

## Задача 8. Проверка всех вариантов через `never`

**ID вопроса:** Задача 8. Exhaustiveness через `never`

Добавь проверку, что все состояния обработаны.

> [!question]- Разбор
> ```ts
> function assertNever(value: never): never {
>   throw new Error(`Unexpected state: ${String(value)}`);
> }
>
> function getFormLabel(state: FormState): string {
>   switch (state.status) {
>     case 'editing':
>       return 'Edit';
>     case 'submitting':
>       return 'Saving';
>     case 'submitted':
>       return `Saved ${state.id}`;
>     case 'failed':
>       return state.error;
>     default:
>       return assertNever(state);
>   }
> }
> ```
