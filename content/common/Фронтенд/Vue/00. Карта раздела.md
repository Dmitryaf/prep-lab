# Vue

Основной маршрут даёт основу Vue 3 и Composition API. Для сложных вакансий добавлены прикладные углубления; их выбирают по требованиям роли.

## Применение в проектах

Сначала пройди сохранение формы по исходникам своего приложения; для отдельного учебного варианта есть [[Собеседования/Проектирование/Клиентское приложение#Бизнес-форма с согласованием|учебный разбор формы]]. Затем найди локальное состояние, производные значения, эффекты и общий store. Изучай нужные механизмы Vue по этой цепочке. Не нужно заранее читать каждый компонент.

## Быстрое повторение

- `ref` и `reactive`, потеря реактивности;
- `computed` против `watch` и `watchEffect`;
- props, emits, slots и однонаправленный поток данных;
- composables, жизненный цикл и очистка ресурсов побочных действий;
- Router, Pinia и выбор владельца состояния;
- гонки запросов, большие списки и тестирование.
