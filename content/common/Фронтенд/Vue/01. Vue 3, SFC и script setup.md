# Vue 3, SFC и script setup

> [!summary]
> Vue связывает данные с интерфейсом: компонент описывает, что показать, а Vue обновляет DOM при изменении использованных данных. SFC объединяет шаблон, логику и стили одного компонента; script setup упрощает запись его логики.

## Зачем нужен Vue

Vue берет на себя связку:

```text
state -> template/render -> DOM update
```

Разработчик описывает состояние, шаблон и реакции на события, а Vue синхронизирует UI с данными.

## Component-based UI

Компонент инкапсулирует часть интерфейса:

- входные данные через props;
- локальное состояние;
- события наружу;
- шаблон;
- стили;
- переиспользуемую логику через composables.

## SFC

Однофайловый компонент Vue (SFC) обычно состоит из трех частей:

```vue
<script setup lang="ts">
import { ref } from 'vue';

const count = ref(0);
</script>

<template>
  <button @click="count += 1">{{ count }}</button>
</template>

<style scoped>
button {
  padding: 8px 12px;
}
</style>
```

В template ref автоматически unwrap-ится, поэтому пишем `count`, а не `count.value`.

## `<script setup>`

`<script setup>` - compile-time синтаксис поверх Composition API. Все top-level переменные доступны в template, а `defineProps`/`defineEmits` используются без импорта.

```vue
<script setup lang="ts">
type Props = {
  title: string;
};

defineProps<Props>();
</script>

<template>
  <h1>{{ title }}</h1>
</template>
```

## Options API

Options API все еще встречается в legacy-коде:

```js
export default {
  data() {
    return { count: 0 };
  },
  computed: {
    double() {
      return this.count * 2;
    },
  },
};
```

На собеседовании достаточно сказать: Options API группирует код по опциям, Composition API - по логике и лучше подходит для сложных компонентов и composables.

## Частые ошибки

- Объяснять Vue как "магический DOM". Лучше говорить про реактивное состояние и render/update.
- Считать, что Composition API нужен только для больших проектов.
- Путать `<script setup>` с отдельной возможностью среды выполнения: этот синтаксис обрабатывает компилятор.
- Писать business logic прямо в template.
- Дублировать DOM/Event Loop объяснения вместо ссылок на JS/Browser API.

## Как ответить на собеседовании за одну минуту

Vue - framework для component-based UI. Компонент описывает state, template и события, а Vue обновляет DOM при изменении реактивных зависимостей. В Vue 3 основной подход - Composition API, часто через SFC и `<script setup>`. Options API встречается в старом коде, но composables и группировка логики делают Composition API удобнее для сложных сценариев.
