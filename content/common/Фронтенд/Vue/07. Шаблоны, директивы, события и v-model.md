# Шаблоны, директивы, события и v-model

> [!summary]
> Шаблон показывает, как данные превращаются в интерфейс: что вывести, какой список построить и что сделать по клику. Директивы Vue добавляют эти правила к обычному HTML.

## Conditional rendering

```vue
<p v-if="isLoading">Loading</p>
<p v-else-if="error">{{ error }}</p>
<UserList v-else :users="users" />
```

`v-if` добавляет/удаляет элемент. `v-show` переключает CSS-display, но элемент остается в DOM.

## List rendering

```vue
<UserCard
  v-for="user in users"
  :key="user.id"
  :user="user"
/>
```

`key` должен быть стабильным id, а не индексом, если порядок списка может меняться.

## Event handling

```vue
<button @click="save">Save</button>
<form @submit.prevent="submitForm">...</form>
```

Модификаторы вроде `.prevent`, `.stop`, `.once` - удобный синтаксис поверх DOM-событий.

## Bindings

```vue
<img :src="avatarUrl" :alt="user.name">
<button :disabled="isSaving">Save</button>
<div :class="{ active: isActive }" />
```

## `v-model`

На обычном элементе input:

```vue
<input v-model="email">
```

На компоненте:

```vue
<BaseInput v-model="email" />
```

Компонент должен принимать `modelValue` и emit-ить `update:modelValue`.

## Формы

Для простых форм достаточно local state. Pinia нужна, если состояние переиспользуется между экранами, переживает переходы или является доменным shared state.

## Частые ошибки

- Использовать index как key в изменяемом списке.
- Прятать тяжелый компонент через `v-show`, когда нужно освобождать ресурсы.
- Использовать `v-if` и `v-for` на одном элементе без явной необходимости.
- Писать сложные вычисления прямо в template.
- Путать данные DOM-события с Vue emits.

## Как ответить на собеседовании за одну минуту

Template во Vue описывает, как состояние превращается в DOM. `v-if` создает и уничтожает узлы, `v-show` только скрывает. `v-for` требует стабильный `key`, чтобы Vue корректно сопоставлял элементы. `@event` вешает обработчик, modifiers упрощают частые DOM-паттерны. `v-model` - двусторонний binding, а на компоненте это prop `modelValue` плюс event `update:modelValue`.

## Вопросы для самопроверки

- Чем `v-if` отличается от `v-show`?
- Почему index key опасен?
- Как работает `v-model` на компоненте?
- Когда форма должна уйти в Pinia?

## Практические задачи

1. Исправь список с `:key="index"`.
2. Выбери `v-if` или `v-show` для модального окна.
3. Опиши custom input с `v-model`.

> [!question]- Разбор
> Для списка пользователей лучше `:key="user.id"`. Для модалки выбор зависит от цены mount/unmount и необходимости сохранять внутреннее состояние. Custom input смотри в [[Фронтенд/Vue/04. Компоненты, props, emits и slots#v-model|Компоненты, props, emits и slots]].
