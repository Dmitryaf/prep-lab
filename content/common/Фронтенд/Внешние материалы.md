# Внешние материалы

Внешние материалы используются только под конкретный пробел. Основной источник подготовки — заметки этого хранилища и реальные вопросы из раздела [[Собеседования/00. Карта раздела|README]].

## JavaScript и web platform

- [learn.javascript.ru](https://learn.javascript.ru/) — системное повторение JavaScript.
- [Дока](https://doka.guide/) — справочник по web platform на русском языке.
- [Lydia Hallie: JavaScript Questions](https://github.com/lydiahallie/javascript-questions) — короткие вопросы на понимание JavaScript.
- [BigFrontend.dev](https://bigfrontend.dev/) — практические frontend-задачи.

## Архитектура и качество кода

- [Refactoring.Guru](https://refactoring.guru/ru/design-patterns) — паттерны проектирования и рефакторинг.
- [SOLID Book](https://solidbook.vercel.app/) — обзор SOLID.

## Алгоритмы

- [NeetCode](https://neetcode.io/) — маршруты и паттерны решения задач.
- [LeetCode](https://leetcode.com/) — практика задач.
- [LeetCode Patterns](https://seanprashad.com/leetcode-patterns/) — подборка частых паттернов.

## Правило отбора

- Не собирать новые длинные списки ссылок без назначения.
- Сначала сформулировать пробел, затем выбрать один источник и одну практическую задачу.
- После изучения зафиксировать результат во внутренней заметке, а не копировать внешний материал целиком.
