## Что нужно понимать

- HTTP организует обмен: клиент отправляет запрос, сервер возвращает ответ;
- метод описывает действие, статус — результат, заголовки — параметры обмена, а тело содержит передаваемые данные;
- HTTPS — HTTP поверх защищённого TLS-канала;
- HTTP cache управляется заголовками вроде `Cache-Control`, `ETag`, `Last-Modified`;
- REST, GraphQL и WebSocket решают разные задачи API;
- CORS подробно разобран в [[Фронтенд/API браузера/05. Fetch, CORS и сетевые запросы/02. Same-origin policy, CORS и preflight|Same-origin policy, CORS и preflight]].
