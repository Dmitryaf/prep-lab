# Подключение помощника Frontend Lab

Встроенный адаптер использует отдельное подключение Codex CLI. Чтение базы, интервью и повторение доступны без него. Данные подключения принадлежат экземпляру; настольная сессия не используется автоматически.

## Локальный Node-запуск

Из корня приложения при установленном CLI:

```sh
node --experimental-strip-types server/infrastructure/codex/cli.ts login
node --experimental-strip-types server/infrastructure/codex/cli.ts status
```

Завершите вход по выданной ссылке на том же компьютере. Эти команды выполняют вход и проверку состояния, а не тестовый вопрос модели. CLI и сервер должны использовать один `FRONTEND_LAB_DATA_DIR`.

`FRONTEND_LAB_LOCAL_LOGIN=1` включает локальный UI-вход, когда браузер и сервер находятся на одной машине. `CODEX_COMMAND` позволяет задать другой executable; на Windows используется путь к `.exe`. Совместимость определяется адаптером `server/infrastructure/codex/` и CLI, включённым в Dockerfile.

## Docker

Образ содержит CLI, а локальный вход в Compose отключён. Сначала выполните вход административным скриптом на машине с браузером и установленными зависимостями приложения. Он сохраняет `.local/instance/assistant/credentials.json` либо файл в выбранном data directory.

Импорт в том из PowerShell:

```powershell
docker compose stop frontend-lab
Get-Content -Raw -LiteralPath '.local/instance/assistant/credentials.json' | docker compose run --rm --no-deps -T frontend-lab node --experimental-strip-types /app/admin/server/infrastructure/codex/cli.ts import-stdin
docker compose up -d frontend-lab
```

Для удалённого сервера передайте файл защищённым каналом и импортируйте на сервере. Файл содержит credentials: храните его закрыто и не добавляйте в Git. Не используйте одну обновляемую сессию одновременно на нескольких серверах.

## Работа

Состояние видно в «Промптах» и «Своих материалах». Обсуждения, генерация и анализ используют одно активное выполнение. Сервер формирует задание, а переданные заметки и исходники остаются недоверенными данными.

Генерация сохраняет черновик, анализ — предложение; изменение активной базы требует принятия. Отмена, закрытие страницы и restart не отправляют запрос повторно. После потери соединения проверьте сохранённое состояние перед новым запросом.

Вход и реальные запросы — разные действия. Автоматические проверки используют подготовленные ответы; они не подтверждают доступность конкретной модели или лимит аккаунта.
