# Подключение и обновление источников

## Два пути

«Свои материалы» принимает готовые Markdown-заметки без помощника либо анализирует учебные материалы и код с помощником. Загрузка файлов относится к компьютеру браузера; путь к папке относится к машине сервера.

Готовые заметки проходят preview и явное принятие. Анализ сначала создаёт сохраняемое задание, затем предложения для базы или разбор проекта. Обновление использует сохранённый контекст и неизменённые части анализа; прерванное задание не возобновляется автоматически после restart.

## Готовые заметки

Откройте «Импорт готовых материалов», задайте название и загрузите Markdown либо ZIP. Поддерживаются обычные Markdown-ссылки, Obsidian-ссылки и скрытый ответ:

```markdown
# Асинхронность

## Что возвращает async-функция?

> [!answer]- Ответ
> Promise, который отражает её результат.
```

Метаданные задаются frontmatter: `title`, `aliases`, `frontendLab.profile` (`shared`, `vue`, `react`), `frontendLab.kind` (`theory`, `practice`, `design`, `behavioral`, `reference`) и `category`. Вид `reference` оставляет материал для чтения без извлечения вопросов.

Ограничения готового импорта: до 200 Markdown-файлов, 1 МБ на файл, 8 МБ текста; для ZIP — до 2000 записей и 8 МБ распакованного содержимого. Нужен UTF-8. Служебные и скрытые файлы исключаются, содержимое не исполняется.

## Анализ материалов и репозиториев

Выберите «Разобрать проекты» или «Дополнить базу знаний», укажите папки либо загрузите файлы/ZIP. Описание своей роли и пожелания можно добавить отдельно. Подключённый помощник исследует материал; результат просматривается до добавления в базу.

Вход анализа ограничен 8 папками, 2000 файлами, 1 МБ на файл и 12 МБ текста. PDF и неподдерживаемые форматы не превращаются в текст автоматически. Зависимости, служебные/скрытые пути и секреты исключаются. Превышение лимита останавливает чтение, а не создаёт незаметно усечённый снимок.

## Обновления и совместимость

Для обновления готового источника передайте полный новый снимок. Отсутствующий материал становится предложением удаления; загрузка только изменённых файлов не равна обновлению всего источника.

Preview сравнивает старый внешний текст, личную редакцию и новый текст. Конфликт разрешается явно; правки preview можно сохранить отдельно. Принятие проверяет ссылки и актуальность ревизии и транзакционно изменяет активную базу. Пустой/недоступный снимок не означает удаления.

Переименование с неизменённым содержимым распознаётся; при одновременной правке задайте соответствие старому материалу/заголовку. ID вопросов, алиасы и исторический прогресс сохраняются. Внешние файлы не переписываются.

## Разрешённая папка сервера

На удалённом сервере папка должна находиться в разрешённом корне. Владелец установки подключает её read-only и выполняет:

```sh
node --experimental-strip-types scripts/sources.ts allow personal "Моя база" /absolute/knowledge
```

В Docker административный скрипт находится в `/app/admin/scripts/sources.ts`. Символические ссылки/junction не поддерживаются. Пример подключения тома и резервные копии — в [self-hosted](self-hosted.md).

Источники кода: `server/infrastructure/sources/`, `server/application/sources.ts`, `domain/source/`, `domain/knowledge/`, `scripts/sources.ts`.
