# Голосовой ввод

В ответах интенсива, рассказе о проекте и обсуждениях используется одно поле: в нём можно печатать и диктовать. Кнопка микрофона находится внутри поля справа внизу.

1. Включите запись и разрешите доступ к микрофону. Запись можно поставить на паузу и продолжить.
2. Нажмите галочку «Завершить запись». Распознавание начнётся сразу, и речь добавится после текущего текста.
3. Продолжайте редактировать ответ в том же поле. Печатать можно и во время распознавания.

В интенсиве ответ сохраняется как обычный текст. В обсуждении сообщение отправляется отдельно стрелкой «Отправить» рядом с микрофоном. При ошибке распознавания запись остаётся доступной для прослушивания, скачивания и ручного повтора. До завершения или отмены диктовки смена вопроса и раздела блокируется. Перезагрузка страницы закрывает запись: браузер попросит подтвердить выход.

## Установка на Windows x64

В каталоге Prep Lab выполните:

```sh
npm run speech:setup
```

Скрипт скачивает [whisper.cpp](https://github.com/ggml-org/whisper.cpp) сборки `b5454` и многоязычную модель `small-q5_1` из [репозитория моделей](https://huggingface.co/ggerganov/whisper.cpp). Размер модели — около 190 МБ. Для обоих файлов проверяется SHA-256. Они хранятся в закрытом каталоге `.local/speech/` либо в `speech/` внутри `FRONTEND_LAB_DATA_DIR`.

После установки нажмите «Проверить подключение» в голосовом вводе или обновите страницу. Отдельно запускать Whisper не требуется: Prep Lab вызывает его при распознавании. Ярлык и обычные команды запуска используют одну установку.

Если корпоративный сертификат вызывает ошибку `SELF_SIGNED_CERT_IN_CHAIN`, запустите установку в PowerShell с системным хранилищем сертификатов:

```powershell
$env:NODE_USE_SYSTEM_CA = '1'
npm run speech:setup
```

## Другие системы и модели

Установите `whisper-cli` по инструкции whisper.cpp и скачайте совместимую многоязычную модель GGML. Перед запуском Prep Lab задайте абсолютные пути:

```sh
PREP_LAB_WHISPER_BIN=/path/to/whisper-cli
PREP_LAB_WHISPER_MODEL=/path/to/ggml-small-q5_1.bin
```

Приложение распознаёт русскую речь. Подключение помощника и его провайдер не влияют на распознавание.

## Где обрабатывается аудио

Браузер записывает звук и отправляет его серверу вашего экземпляра Prep Lab. Whisper обрабатывает запись на этом компьютере, без внешнего сервиса. При локальном запуске браузер и сервер работают на одном компьютере. Если Prep Lab установлен на другом сервере, распознавание выполняется там.

Для доступа к микрофону нужен `localhost`, `127.0.0.1` или HTTPS. Одна запись ограничена 15 минутами; сервер выполняет одно распознавание за раз. Временные серверные файлы удаляются после завершения или отмены обработки. При принудительном завершении процесса папки `recording-*` могут остаться в закрытом каталоге `speech/`. Аудио не добавляется в базу и не отправляется помощнику. В базу попадает только вставленный текст через обычное сохранение ответа или отправку сообщения.
