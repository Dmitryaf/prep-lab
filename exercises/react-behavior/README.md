# Поведение компонентов React

Стенд с исходниками, DOM-тестами и интерактивной страницей. Ответами загрузчика можно управлять вручную; сетевые запросы не выполняются. Нужен Node.js 22.22.3+ или 24.15+.

Распакуйте ZIP, откройте терминал в `react-behavior`:

```sh
npm ci --ignore-scripts
npm test
npm run typecheck
npm run build
npm run dev
```

Первичная установка требует доступа к npm. Vite напечатает локальный адрес; сервер слушает 127.0.0.1. Исходники полностью входят в ZIP и не требуют базы заметок. `src/examples` содержит готовые реализации для сверки после своей попытки; тесты запускают эти же компоненты.

## Сценарии

- Композиция: измените имя. Поле и приветствие обновляются от одного состояния родителя. В тесте проверьте новое значение props без устаревшей локальной копии.
- Поиск: введите A, дождитесь запроса, введите B, завершите B перед A. Поздний A не меняет видимый результат, ошибку и загрузку. Повторите со старой ошибкой и сменой организации. Загрузчик намеренно игнорирует отмену.
- Форма: отправьте имя с включённым отказом. Ввод остаётся, ошибка видна; отключите отказ и повторите сохранение.
- Идентичность строк: измените черновик, переставьте список. Текст должен остаться у той же записи. Измените `key` на индекс и объясните отличие.
- Подписка: вызовите resize, смените callback, вызовите снова, отключите компонент и повторите. После отключения новых вызовов нет.

Сначала запишите ожидаемое поведение и напишите собственную реализацию в копии исходника. Затем выполните тесты и сравните с решением. Для контроля тестов уберите проверку актуальности в `src/examples/search.tsx`: сценарии поздних ответов должны отказать. Верните защиту и убедитесь, что проходят снова.

Тесты в jsdom проверяют состояние и DOM. Layout и визуальное поведение проверяйте на странице стенда, производительность — в браузерном профилировщике. Сеть в тестах имитируется. React Compiler, Next.js и RSC здесь не используются.

Справка: [React — preserving state](https://react.dev/learn/preserving-and-resetting-state), [React act](https://react.dev/reference/react/act), [Testing Library — guiding principles](https://testing-library.com/docs/guiding-principles/).
