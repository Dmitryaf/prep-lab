# Поиск с поздними ответами

Практикум Vue 3 / TypeScript. Тесты управляют ответами загрузчика без сетевых запросов.

## Запуск

Нужен Node.js 22.22.3+ или 24.15+. Распакуйте архив, откройте терминал в `request-lifecycle` и выполните:

```sh
npm ci --ignore-scripts
npm test
npm run typecheck
```

Установка требует доступа к npm; следующие запуски тестов работают локально. Здесь нет приложения поиска и настоящего backend: тесты управляют моментом ответа транспорта. `/api/search` в `searchUsers.ts` — контракт учебного адаптера, а не API Frontend Lab.

## Самостоятельная попытка

1. До чтения `useLatestSearch.ts` прочитайте условия в `useLatestSearch.test.ts`. Объясните, почему отмены запроса A недостаточно, если его транспорт всё равно завершится.
2. Сохраните свою копию `useLatestSearch.ts`. Реализуйте тот же контракт: новый непустой запрос очищает результат и ошибку, выставляет загрузку; только актуальный запрос меняет состояние. Пустой ввод очищает поиск; остановленный scope больше не принимает результаты.
3. Запустите `npm test`, исправьте отказ и объясните, какую последовательность событий проверяет каждый тест. Сравнивайте с исходной реализацией после собственной попытки.

Для контролируемого воспроизведения дефекта временно замените `const isCurrent = ...` на `const isCurrent = () => true`. Поздний A перезапишет B; старая ошибка и `finally` повлияют на новый поиск. Тесты должны упасть. Восстановите проверку актуальности и повторите запуск.

Проверь поздний успех и ошибку, отмену, пустой ввод, смену строки до запуска watcher и остановку scope. Заверши запуском `npm test` и `npm run typecheck`.

Справка: [Vue watch cleanup](https://vuejs.org/guide/essentials/watchers.html#side-effect-cleanup), [AbortController](https://developer.mozilla.org/en-US/docs/Web/API/AbortController).
